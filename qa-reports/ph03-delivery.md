## النتيجة وسلوك المحرك

المحرك `0.3.0` يقرأ معادلة خطية واحدة في س، ويحتفظ بالنص الخام وAST ذي source spans بوحدات Unicode code points، ويولد التطبيع/العرض من الشجرة. يسمح بالأرقام الشرقية وASCII، والإشارات والأقواس والضرب الضمني المحدد والكسور/المقامات العددية الثابتة. لا يحول x إلى س، ولا يفكك جا إلى متغيرات.

تطبق حراسة البنية قبل التبسيط: `س/س` و`١/(س−س+١)` ممتنع عنهما للمقام المتغير، و`٠×س×س` ممتنع عنه رغم إمكانية اختفائه حسابيًا. `١/٢س` ملتبس ويطلب أقواسًا. لا eval/exec أو sympify/parse_expr/LaTeX حر على النص. لا ثقة في AST يرسله العميل.

يحسب Fraction معاملات خطية ومجموعة حل دقيقة: singleton أو all_reals أو empty. يبني SymPy من العقد الموثوقة فقط، ويقارن المعاملات والحل والتعويض بمسار مستقل حسابيًا. التكافؤ يقارن **مجموعتي الحلول**؛ عدم التكافؤ ينتج شاهدًا تنتمي قيمته لإحدى المجموعتين فقط، ويعاد فحصه قبل الإرجاع. اختلاف الحساب/فشل الشاهد ينتج inconclusive، وتعطل العامل/المهلة ينتج service_error.

| المثال | الناتج الفعلي |
|---|---|
| `٢(س + ٣)=١٠` ← `س + ٣=٥` | verified_valid؛ المجموعتان `{٢}` |
| `٢(س + ٣)=١٠` ← `٢س + ٣=١٠` | verified_invalid؛ `{٢}` مقابل `{٧/٢}`؛ شاهد س=٢ يحقق السابقة فقط |
| `٢س=٤` ← `٠=٠` | verified_invalid؛ singleton مقابل all_reals؛ شاهد من الفرق |
| `س/س=١` | unsupported / VARIABLE_DENOMINATOR، لا اختزال يخفي المجال |
| `س/٠=١` | syntax_error / DIVISION_BY_ZERO، لا وصف مفاهيمي |
| تجاوز حجم rational | inconclusive، دون evidence أو نجاح جزئي |
| قتل عامل حساب متأخر/منهار | service_error، لا verified_invalid افتراضي |

عمليات `/internal/v1/math/parse` و`verify-transition` و`check-final` تطابق **العقد الداخلي الموجود**، بمصادقة الخدمة ورفض الحقول/النسخ والأنواع غير المعروفة. check-final يعيد العزل والتعويض فقط؛ لا completed أو mastery أو صلاحية اعتماد سلسلة. NestJS هو API العام الوحيد، ولم يبن adapter أو DB أو جلسات/واجهات تحقق عامة.

- **التكامل مؤجل:** لا PH-04/05 أو NestJS adapter/جلسات/DB أو revision race/idempotency/stale persistence/E2E طالب. echo النسخ داخل هذا العقد لا يثبت اعتمادًا ذريًا في DB.
- **لم تُشغل:** قبول 151 حالة كاملة، اختبارات حمل ثقيلة، تجارب قُصّر/AI خارجي، CI بعيد، أو فحص أمني شامل. لا ادعاء جاهزية إنتاجية أو بيانات تعلم.
