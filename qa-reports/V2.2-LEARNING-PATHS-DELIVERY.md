## النتيجة

أضيفت المسارات والوحدات والدروس بإصدارات، واستوديو تأليفها والتحقق منها ومراجعتها ونشرها، فوق النظام القائم. أصبحت واجهة الطالب تستهلك APIs فعلية للتعلم المباشر والتقييم والتوصية والتدريب وإعادة القياس والتقدم والاستئناف.

رحلة الجبر المثبتة عبر HTTP: **مسودة درس → تحقق SymPy → مراجعة ونشر بحساب اختبار مخول → تقييم مستقل من 10 أسئلة → خطأ متحقق وتوصية متحفظة → تدريب H1/H2 بمساعدة → سؤالان جديدان مستقلان → أدلة فهم محدودة → استئناف النسخ المثبتة بعد تحديث المحتوى**. التجربة تستخدم PostgreSQL ومحرك الرياضيات الحقيقيين، وليست mocks للرحلة النهائية.

الفيزياء تستخدم البنية نفسها ومتحقق القيمة والوحدة؛ ثبت تدريبها وقياسها بأسئلة جديدة وحماية مراجعاتها. Python له مسار ودرس قراءة فعليان؛ **تقييم المسارات البرمجي محجوب** في هذه المرحلة حتى تهيئة وقبول Runner المعزول. لم يُشغّل كود طالب أو Gemini مدفوع.

محتوى التسليم الجديد **21 مسودة**. النشر الآلي داخل الاختبارات يخص fixtures اصطناعية مؤقتة موسومة `TEST_ONLY` و`automated_test_fixture_not_human`، ولا يُعد اعتمادًا تربويًا لهذه المسودات.

```powershell
npm run build
node tools/test-learning-paths.mjs
```

لإبقاء نسخة اصطناعية مؤقتة للتجربة:

```powershell
node tools/test-learning-paths.mjs --serve
```

تنتج بياناتها في `.local/v22-preview.json` وتفتح على **https://127.0.0.1:8461** لمدة أقصاها10 دقائق ثم تُنظف. تعتمد المعاينة على شهادة ومفتاح الاختبار الموجودين في `.local/ph09-tls/cert.pem` و`key.pem`؛ يلزم إعداد HTTPS موثوق في بيئة المراجعة. إذا ظهر خطأ الشهادة، تبقى تجربة المتصفح محجوبة ولا تسجّل نجاحًا بتجاوزه. لا تتضمن الروابط أسرار جلسات، ومسارا التحويل إلى teacher/student موجودان في test harness فقط، ولا يدخلان تطبيق الإنتاج.

سيناريو الجبر من6 خطوات على بيئة اختبار ذات HTTPS صالح:

1. افتح `/__v22_test_teacher` ثم «استوديو المحتوى ← المسارات والدروس». أنشئ/راجع درس التوزيع، عاين المحتوى وتحقق من الأمثلة، ثم submit/approve/publish بحساب مخول. في بيانات التسليم الحقيقية استخدم «استيراد الحزمة المسودة»؛ لا تعتمدها دون مراجعة الشخص المسؤول. للنشر الجزئي احذف روابط الدروس الخمسة غير المراجعة من المسار قبل نشره.
2. افتح `/__v22_test_student` ثم «الرياضيات ← الجبر الأساسي ← توزيع الأقواس». اقرأ المثالين، ولاحظ أن الاطلاع لا يمنح دليل فهم.
3. اختر «اختبر مستواك». أرسل تحويل توزيع غير مكافئ مناسبًا للسؤال المعروض، مثل `٢(س + ٤)=١٤ → ٢س + ٤=١٤` إن ظهر هذا السؤال. شاهد حكم عدم التكافؤ، ثم ملخصًا يقترح مراجعة الدرس بصياغة محتملة ومصدر دليل؛ لا تضف hints أثناء القياس.
4. افتح الدرس الموصى به، وابدأ التدريب بسؤال مختلف؛ احفظ محاولة ثم اطلب H1 وبعدهH2. النتيجة بمساعدة، وإذا كانت محاولة مستقلة فوافق صراحة على مغادرة القياس قبل عرض التلميح.
5. اختر «سؤال جديد بعد التدريب». أجب عن السؤالين الجديدين دون مساعدة؛ قارن التقدم مع المحاولات السابقة. نجاح سؤال واحد يعني دليلًا محدودًا، ولا يكفي وحده لحالة استقلال مجمّعة.
6. أعد فتح الصفحة لاستئناف النسخة والمسودة في التبويب نفسه. من المعلم أنشئ revision جديدة؛ تبقى محاولة الطالب على نسختها السابقة. التقييم المملوك لغير الطالب يرجع404. بدّل إلى الفيزياء لتجربة قيمة ووحدة، ثم Python لرؤية القراءة والحجب المعلن للتقييم.

قد يتناقص البنك الجديد بعد التعرض للأسئلة؛ هذه حماية متعمدة للقياس، ورسالة نقص التغطية جزء من التجربة. يمكن إعادة إنشاء قاعدة الاختبار المؤقتة لرحلة جديدة دون المساس بقاعدة المستخدم.
