## المنفذ

واجهة React متصلة بـNestJS لقائمة المحتوى والبحث والمهارة والحالة والصعوبة؛ إنشاء وتحرير JSON منظم ومعاينة عربية، وعرض فرق النسخ، وتحقق التخصص، ومراجعة واعتماد ونشر وأرشفة ونسخة جديدة وتراجع. استيراد JSON مع dry-run وأسباب الرفض وتصدير بلا بيانات طالب. CRUD المسودات يحفظ expectedRevision؛ كل كتابة تستعمل CSRF/Origin وIdempotency-Key وملكية جلسة الحساب والدور.

تسلسل المادة والوحدة والدرس والمهارات محفوظ داخل الحمولة ذات الرموز الثابتة. الأدوار teacher/content_manager للتحرير، وadmin للاعتماد والنشر والتراجع. الحالة `draft → in_review → approved → published → archived`؛ المحتوى المنشور والأحداث محمية في SQL من الكتابة فوق التاريخ. التلميحات ومفاتيح الإجابة مرئية للحساب المخول فقط؛ الطالب يرى إسقاطًا صريحًا للمحتوى الرئيسي المنشور دون حقول خاصة.

كل نشر جبر يولّد إصدارًا أصليًا جديدًا بدل تعديل عضوية release مجمدة. انشر العلاج والنقل المراجعين أولًا، ثم الرئيسية: ينشئ الخادم snapshot داخل إصدار الرئيسية، يثبت العائلة والقيم والصعوبة والمهارة وبصمات المصدر، ويضيف `content_pairings` وتلميحات النسخ. يرفض الرئيسية برسالة مفيدة عند غياب زوج متوافق. المصدر التعليمي السابق لا يتغير. كتالوج الطالب يحجب العلاج والنقل حتى إسنادهما. يحتفظ استئناف المحاولة بالمسألة ذات الإصدار الأصلي بعد أرشفتها. كتالوج التشخيص يعاد استعماله من نسخة مراجعة فقط للمهارة نفسها، دون إنشاء نمط خطأ أو اعتماد جديد.

التحقق قبل النشر: حل الجبر ومثال صحيح وخاطئ عبر المحرك الخاص؛ حساب فيزياء ووحدة متوافقة؛ حل Python المرجعي يجتاز جميع الاختبارات في Runner. غياب المحرك أو Runner يمنع النشر، ولا يعتبر نجاحًا افتراضيًا.
