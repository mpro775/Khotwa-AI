## سلوك موثق

- GET للقرار/الأبعاد/الخريطة/المستحق/الأهداف/التأمل لا يجلب بنك الأسئلة. تبدأ الأسئلة فقط بعد POST صريح يفحص الخادم أهليته.
- 403/404 للميزات المغلقة يخفي القسم المتأثر ويبقي واجهة V2.2؛ فشل الشبكة أو الخدمة لا يُعرض كخطأ مفاهيمي.
- flags مستقلة: اختُبر تعطيل A1 مع بقاء A2 وA5 متاحين، دون أي طلب كتالوج/بنك/مسألة.
- زر «احفظ نتيجة المراجعة المتحققة» يكمل مسار A5 عبر `/reviews/:id/finish` ثم يعيد قراءة أبعاد A2؛ لا يستنتج المتصفح نتيجة الاحتفاظ.
- دعم الحوار/كشف خطوات القياس/السؤال التشخيصي المرتبط بقياس مستقل يسبقه تأكيد واضح، مع إعادة تحميل جلسة القياس من الخادم. الحماية الفعلية للقياس والملكية وعدم التكرار داخل NestJS، وليست قرارًا محليًا.
- IDs في sessionStorage ليست إثبات ملكية. تُعاد قراءة النشاط/scaffold/tutor من الخادم، ويمسح تبديل الهوية prefix القائم `khotwa-path:`.
- كتابة الطالب في التأمل والحوار تظهر كعقد نصية React، بلا HTML خام. لا يتصل المتصفح بـLLM أو Runner أو Python مباشرة.
- A2 لا يعرض masteryPercent/probability، ولا يتخذ ثقة الطالب الذاتية حكمًا علميًا.
- تعديل الهدف يعيد استخدام النموذج الموسوم عربيًا (وصف ≤240 محرفًا، هدف 1…5)، مع حفظ/إلغاء وحالة busy وخطأ؛ يرسل expectedRevision فقط مع الحقول المعدلة، ويحتفظ الخادم بخط أساس الأدلة. لا يعيد المتصفح احتساب تحقيق الهدف.
- إخفاء `completion_step.steps` هنا خاص بالعرض؛ لا يزعم هذا التقرير أن الواجهة تنقح DTO الخادم أو أن إخفاء العرض بديل عن ضبط payload العام.
