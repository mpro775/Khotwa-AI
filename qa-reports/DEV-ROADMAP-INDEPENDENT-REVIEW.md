# مراجعة مستقلة لتكامل خارطة التطوير

- التاريخ: 2026-11-07؛ الفرع `codex/posthack-roadmap`.
- المراجع: وكيل الواجهة، في جولة منفصلة لمراجعة مسارات الخادم والحدود مع React.
- الطريقة: قراءة الشيفرة والعقود وقيود SQL وتتبع الحالات والتزامن نظريًا. **لم تُشغّل خدمات أو قاعدة بيانات أو SMTP أو Runner أو اختبارات ثقيلة**. لا تمثل هذه المراجعة اختبار تكامل حيًا أو اعتمادًا بشريًا تخصصيًا.
- النطاق: `content-studio.ts`، `studio-tutoring.ts`، `studio-pairings.ts`، `programming.ts`، `programming-runner.ts`، `product-core.ts`، `accounts.ts`، جسر الهوية في `store.ts`، وواجهات React المستهلكة.

## حدود أخرى راجعتها

- حُجب عرض العلاج والنقل كمسائل عامة حتى لا تُكشف مسألة النقل قبل إسنادها؛ الاستعادة المثبتة للمحاولة المملوكة تظل منفصلة عن الكتالوج العام.
- فحوص `expectedRevision` موجودة في تلميحات البرمجة وإعادة التسليم، والمساعدة السابقة تستمر وتمنع الدليل المستقل، حتى عند إنشاء محاولة جديدة لنفس الإصدار.
- نتائج الاختبارات المخفية ترجع مجملة؛ لا يرسل public projection الحل المرجعي أو hidden tests. مخرجات الحالات المخفية لا تنسخ إلى stdout العام.
- ربط الضيف يتطلب حسابًا وجلسة ضيف من المتصفح نفسه وموافقة صريحة، ويثبت provenance، ويرفض الربط بحساب آخر ويعزل البيانات الاصطناعية.
- الأصل القديم للمحاولة يُقرأ عبر مسار مملوك مثبت؛ لا يستبدل عرض المحاولة بالإصدار العام الأحدث.
