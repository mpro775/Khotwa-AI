## البيان وBOM وإعادة الفحص

[D0-RELEASE-MANIFEST.json](D0-RELEASE-MANIFEST.json) يسجل HEAD/tree والفرع وحالة العمل، وجميع ملفات Git tracked وغير المتجاهلة الحالية عدا مجلدي تقارير التسليم. تقارير D0 الخمسة، كل أدلتها، ومراجع A/B/C وV2.2 الأساسية مفهرسة مستقلة. لا يشمل `.env` أو `.local` أو المخرجات أو الأرشيفات، ويستبعد البيان نفسه حتى لا ينشأ hash ذاتي. أي ملف خاص أو symlink في الجرد يوقف الأداة قبل قراءته.

البصمة المجمعة هي SHA256 للنص `JSON.stringify(files)`، حيث ترتب المسارات ترتيبًا ثابتًا ولكل ملف `path/bytes/sha256` من **بايتاته الخام**. لا يحول البيان CRLF إلى LF لتجاوز اختلاف فعلي؛ تحفظ بصمة LF للتحقيق في مرجع C فقط. يسجل BOM نسخ/سلامة وترخيص الحزم كما في `package-lock.json` وبصمات `pyproject.toml` وملفي Python lock؛ ليس تدقيق تراخيص أو ثغرات أمنية. صور Docker الفعلية ونسخ الأدوات في [environment.json](D0-evidence/environment.json).

```powershell
node tools/d0-release-integrity.mjs --record
node tools/d0-release-integrity.mjs --check
```

`--record` ينتج snapshot جديدًا **دون موافقة**؛ `--check` لا يعيد توليد أو تصحيح SHA، ويفشل عند اختلاف HEAD أو الجرد أو الأدلة أو المراجع التاريخية أو BOM. بعد التسجيل لا تحفظ stdout داخل `D0-evidence` لأنه سيغير الجرد نفسه. تعديل تقرير أو إضافة سجل بعد التجميد يتطلب بيانًا جديدًا ومراجعة ما تأثر من الأدلة، ولا يجيز تحويل نتيجة قديمة إلى اختبار على مصدر جديد.
