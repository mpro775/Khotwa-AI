## إثبات الربط بين الطبقات

- الحساب: AccountPanel → موافقتا learning/AI الموثقتان بإصدار السياسة → AccountService/Store → جلسة تعلم ذات علم فعلي → خدمات الجبر والتقدم. جُرّب قبول تقدم isSynthetic=false للمعرّف المطابق في واجهة الطالب، مع بقاء حارس المعلم الاصطناعي مستقلًا.
- Python: المحرر → NestJS → حفظ النص/الحجز → Judge0Runner → تقييم الحالات → إعادة التفويض/المراجعة → عرض الطالب المقتصر على إسقاطه. واجهة المعلم تستهلك نتائج validate العامة/المخفية الخاصة بدورها.
- الفيزياء: اختيار السؤال → المتحقق الداخلي → حلقة مملوكة → إسناد طفل مثبت → استعادة المحاولة → التحقق → نقل مستقل → تقدم. القائمة والتفاصيل تسجل التعرض، فلا يصبح سياق سبق كشفه نقلًا جديدًا.
- التلميح: snapshot قصير → استدعاء المزود خارج المعاملة → schema/معنى مقيد → فحص الموافقة والنسخة عند الحفظ → assistance/event/واجهة. لا يمر كود الطالب أو جوابه أو المرجع أو hidden tests أو هويته إلى Gemini.

هذه مسارات مستهلكة ومخزنة في المصدر، وليست استنتاجًا من وجود route أو شاشة. الفحوص بالمحاكاة لا تثبت تكامل الشبكة أو PostgreSQL الفعلي.
