## سلوك مثبت بأمثلة

للمسألة `٢(س + ٣) = ١٠`: السلسلة `٢س + ٦ = ١٠` ثم `٢س = ٤` ثم `س = ٢` تعود verified_valid وتكتمل فقط بعد check-final والعزل والتعويض. إدراج `٢س + ٣ = ١٠` قبل الجواب `س = ٢` يعطي verified_invalid وشاهدًا، ويمنع الاكتمال رغم صحة الجواب النهائي. انتقال مكافئ غير معزول أو فحص target_edge لا يكمل المحاولة.

مدخلات جديدة مثل `٤(س + ٢) = ٢٠ → س + ٢ = ٥ → ٣ = س` و`−٣(س − ٢) = ١٢ → س − ٢ = −٤ → س = −٢` استعملت Python الحقيقي. القوس الناقص syntax_error، و`جا(س)` unsupported، وتجاوز ميزانية الكسر inconclusive. لا diagnosisCandidate أو أثر مفاهيمي لهذه الحالات. تعطل المحرك يعيد 503 math_unavailable؛ لا يتحول إلى verified_invalid، وتبقى الخطوات محفوظة.

السجل يحفظ raw كما أرسله العميل، والتطبيع وAST والعرض من المحرك مستقلة عنه. لا يحسب React صحة الرياضيات أو يرسل AST موثوقًا. نتائج التحقق التاريخية محفوظة وisCurrent=false بعد التعديل؛ إعادة المفتاح نفسه لا تضاعف الأثر. لا تعتمد النتيجة القديمة تقدمًا أو اكتمالًا.
