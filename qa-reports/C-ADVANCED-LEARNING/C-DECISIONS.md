## قرارات غير محسومة لم تُغلق

- GOLD-DIAG-015 وERR-ALG-05/SK06 وقرارات A-DEC/B العلمية باقية؛ لا تغيير Golden.
- سياسة تجميع آمن وحد k، ربط cohort، بيانات القاصرين، rollout، التشغيل الحقيقي والاحتفاظ النهائي مصدرها المالك المختص. لا رقم جديد أو موافقة مختلقة.
- معايرة pre/post وrubric وقياس أثر التدخل وتنوع الاستراتيجيات تتطلب تعريف بيانات ومراجعة صلاحية؛ المؤشر غير المقاس `null` مع سبب صريح.
- زمن RPO/RTO وSLA لم يقاس أو يعتمد؛ نجاح backup/restore الاختباري ليس وعد خدمة.

## إصلاحات كشفتها الفحوص والمراجعة

حقل evidenceClass في قائمة C أضيف إلى العقد، وتوقعات fixture لصيغ Studio201 ومخرجات review صححت لتتبع العقد الحالي. عولجت نافذة إكمال C5 لتقرأ أول حدث completed بدل updated_at؛ إبطال/نقل الإسقاطات من canonical؛ حماية الحساب الداخلي قبل replay ومنع claim عبر C وحده. نتائج الجولات الأولى محفوظة، ولا تعديل Golden/حكم علمي لإسكات فشل.
