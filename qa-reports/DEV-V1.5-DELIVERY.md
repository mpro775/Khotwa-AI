## المنجز

`compose.beta.yaml` إضافة تشغيل مع اسم وvolume وDB وأدوار مستقلة، TLS عبر Caddy، وعدم نشر PostgreSQL/Python، وقيود موارد، وخدمات backup/retention تحت profile صيانة. `ops/beta-init-db.sh` يفصل مستخدم migrations/owner عن app بلا DDL أو superuser، وعن backup للقراءة، على DB جديدة فقط. `compose.mail-local.yaml` يجهز Mailpit محليًا. لا ملفات أسرار فعلية في هذه الإعدادات.

دخول Beta يعتمد allowlist البريد المحقق، وإيقاف الدخول مركزيًا، وتعليق الحساب وإبطال كل جلساته من admin. تتحقق المسارات الجديدة والجبر القديم من الحساب عند Beta؛ لا يحصل ضيف على مخزن تعلم حساب عبر UUID. لا ترتبط صفحة المعلم التجريبية بمحاولات المتعلمين.

`beta-operations.ts` يجمع مؤشرات API منقحة دون مسارات/هوية/نصوص، بأخذ آخر١٠٠٠ زمن طلب للعامل الحالي وبداية يومUTC. لا يظهر p50/p95 قبل٢٠ عينة. تعرض صفحة admin مؤشرات DB اليومية، وحالة DB، ومساحة القرص، ومصدر التلميحات واستعمال الرموز المعروف والتكلفة المجهولة صراحة، وملاحظات منقحة. توصيل API middleware نفذه قائد التكامل، وتوصيل أحداث التلميح الفعلية نفذه وكيل التعليم.

يوجد حجز ميزانية AI دائم قبل اتصال المزود، مع سقف يومي/شهري ومحلي للحساب وعدد الطلبات/الرموز، واحتساب محافظ لفشل الاستدعاء أيضًا. التكلفة المجهولة أو سقف الصفر يمنع الاتصال ويُبقي fallback المراجع؛ لا تحويل لحصة cost_units القديمة إلى سعر مزعوم. إعداد `BETA_AI_MAX_CALL_COST_MICROS` شرط مستقل. مسار الاستدعاء الفعلي يقيد Gemini بدفاتره وحدوده السابقة؛ لم يستعمل المزود خارجيًا هنا.

Feedback محدود المعدل ومحمِي بالهوية/CSRF وIdempotency ويزيل أنماطًا شائعة للبريد والأسرار. هذا تنقيح مساعد، ولا يتيح إدخال أسرار عمدًا أو وصولًا عامًا إلى الملاحظات.

`tools/beta-backup.mjs` يسحب `pg_dump` بصلاحيات قراءة إلى بث AES-256-GCM دون ملف plaintext، ويحتفظ بعدد محدود من النسخ المشفرة ويكتب تقرير آخر تشغيل فعلي. `tools/beta-restore.mjs` يقبل قاعدة **اختبار** باسم محدد فقط مع تأكيد صريح، ويتحقق من كامل وسمGCM قبل تمرير البيانات إلى PostgreSQL، ويستعيد بمعاملة واحدة دون حذف volumes. لا يدعي إعادة tombstones تلقائيًا؛ التقرير يذكر أنها خطوة تشغيل لازمة قبل إتاحة قاعدة الاستعادة.

ترحيل0011 يستثني مخزن حساب نشط من TTL الضيف؛0015 يمد دالة OWN-11 القائمة لتشمل subject attempts/events وproduct cache وbeta rows التابعة للملاك المؤهلين، دون تغيير مدة الضيف المعتمدة. دالة تنظيف المصادقة المنتهية منفصلة بصلاحية maintenance فقط. أضيف `--auth-cleanup` إلى أداة الاحتفاظ؛ الافتراضي dry-run والجدولة التطبيقية تتطلب profile/صلاحية صريحة. طلب المحو يوقف الوصول ويسجل الطلب، ولا يصفه بمحو نهائي من النسخ.

- مخاطر/متبقي: اختبار معاملات PostgreSQL والترحيلات والاحتفاظ، مراجعة أدوارDB، تجربة الاستعادة والمفاتيح، DNS/TLS، اعتماد الخصوصية قبل متعلمين حقيقيين. لا حالة PASS بديلة لهذه البنود.
- BLOCKER/HIGH المثبتة من الفحوص الخفيفة: لا عيب مفتوح رُصد ضمن العينات المنفذة؛ لا يستنتج من ذلك جاهزية الإطلاق.
- الاعتماد: بانتظار المالك/الأمن/QA؛ لا موافقات أو نتائج بشرية مختلقة، ولا دفع أو نشر عام أو رسائل خارجية من هذا العمل.
