1. `qa-reports/gate-0.md` في آخر مستودع يحمل `APPROVED` مع مراجع وتواريخ وإحالات حقيقية.

## ثوابت لا تتغير

- NestJS الخادم الرئيسي الوحيد الظاهر للمتصفح. **لا FastAPI كباك إند**؛ Python/SymPy محرك رياضي خاص.
- PostgreSQL. Prisma أول مرشح فقط حتى اجتياز PoC القيود/المعاملات؛ لا ترحيلات فعلية قبل الحسم.
- لا تعتبر MathLive معتمدًا قبل فحوص العربية والكسور على الأجهزة في PH-02.
- لا تعيد تعريف APIs دون طلب تغيير واعتماد المستهلكين.
- لا تخزن مفاتيح أو حسابات أو طلاب حقيقيين. لا نشر لخدمات Python/PostgreSQL عامة.
- لا اختبارات تحميل ثقيلة أو نشر إنتاج أو معالجة مدفوعات أو OCR أو توسع خارج P0.
