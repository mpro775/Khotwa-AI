# تشغيل PH-05 ومتابعة الفحص

> بيئة اختبار اصطناعية محلية فقط. لا اعتماد GATE-1 أو نشر عام. تاريخ التسليم: 2026-11-04.

```powershell
npm run verify:ph05
npm run verify:ph05:container
npm run dev:ph05
node qa/ph05-https-probe.mjs
```

الأول يشغل العقود والتنسيق وlint والأنواع والبناء والوحدة وsmoke الخفيف. الثاني يبني صور الاختبار ويشغل PostgreSQL 17.6 وPython الحقيقيين على شبكة داخلية مؤقتة، ويرحّل قاعدة tmpfs خاصة به ويختبر rollback/replay ثم يزيل موارده. لا يستعمل قاعدة Compose التأسيسية. `--skip-build` للتكرار المستهدف فقط إذا بقي المصدر المترجم والاعتماديات مطابقين للصورة.

`dev:ph05` يستعمل `compose.ph05.yaml` ومشروعًا مستقلًا؛ يحفظ عنوانه في `.local/ph05-local.json`. العنوان الحالي https://localhost:8443/؛ المنفذ مربوط بـ127.0.0.1 وحدها. لا منافذ عامة لـAPI أو Python أو PostgreSQL. أعلام PH04 وPH05 مفعّلة لهذه البيئة وحدها؛ تبقى معطلة افتراضيًا في Compose التأسيسي. لا تستخدم هذا الملف لتشغيل بيانات حقيقية.

تولد الأداة شهادة localhost ذاتية التوقيع لمدة سبعة أيام في `.local/ph05-tls` باستخدام OpenSSL، دون تغيير مخزن الثقة. تبقى Cookie Secure وHttpOnly وSameSite وOrigin/CSRF وسياسة CSP مفعلة. فحص Node يثبت الشهادة لهذا الطلب فقط مع تحقق TLS مفعّل؛ ليس دليلًا على ثقة Chrome أو تفاعل واجهة.

توقف Chrome عند `ERR_CERT_AUTHORITY_INVALID`. التعامل مع التحذير تسليم يدوي للمستخدم وفق تعليمات Computer Use؛ اختار المالك «سأكمل هذه الخطوة لاحقًا؛ وثّق المتبقي». لا تستعمل تعطيل TLS أو تبديل إعدادات الأمان لإكمال الفحص. بعد التعامل اليدوي وظهور «حلّك، خطوة بخطوة»، يمكن متابعة القائمة أدناه بالأداة المعتمدة. لا يوجد هاتف حقيقي متاح وفق جواب المالك؛ لا تُحسب المحاكاة بديلًا عنه.

## قائمة الفحص التفاعلي المتبقية

سجّل نسخة المتصفح والجهاز ووقت التشغيل وrun_id وصورًا حقيقية قبل/بعد؛ جميع البنود الآتية **لم تُنفذ على واجهة PH-05 بعد**:

1. ابدأ جلسة ضيف واختر مهارة ثم مسألة الاختبار `٢(س + ٣) = ١٠`. يجب أن تظهر علامة البيانات الاصطناعية. أدخل `٢س + ٦ = ١٠` ثم `٢س = ٤` ثم `س = ٢`؛ احفظ وتحقق. قارن النص الخام والعرض الآتي من المحرك والاكتمال.
2. جرّب `٢س = ١٦` بين خطوتين صحيحتين. يجب ألا يجعل الجواب النهائي الصحيح السلسلة مكتملة؛ افحص شاهد عدم التكافؤ. لا بطاقة تشخيص أو حكم على مفهوم الطالب.
3. جرّب `س + = ٢` و`جا(س)=١`، وكسورًا مثل `س/٢=٣` و`س=١/٢` في المسألة المناسبة. تحقق من الأقواس والسالب وترتيب الأرقام وشكل الكسر؛ لا تتجاوز واجهة الخطوط المائلة بوصفها كسرًا مركبًا مجازًا.
4. انسخ الخام كاملًا وجزئيًا بقائمة الجهاز ولوحة المفاتيح، والصق من داخل المحرر وتطبيق خارجي. قارن Unicode الخام حرفيًا، ثم احفظ وأعد التحقق. افحص المؤشر والحذف والتراجع والإشارات والأقواس في RTL. لا يكفي تطابق HTML أو LaTeX لإثبات المعنى.
5. افحص التأخير/التعطل وإعادة الإرسال دون فقد المسودة. لاختبار سباق مقصود، يمكن للمراجع إنشاء الملف `.local` المقابل داخل حاوية math-proxy: `/tmp/ph05-delay-next` بمحتوى `3000`؛ يؤخر الرد التالي فقط دون تغيير حكم Python. الحاوية خاصة بالاختبار ولا تضيف route عامة. حرر خطوة أقدم أثناء الانتظار؛ يجب إخفاء النتيجة القديمة فورًا ورفض اعتمادها بعد العودة. لا تشغل هذا السيناريو على بيانات حقيقية.
6. أعد فتح الجلسة لاستعادة المحاولة؛ افحص التنقل بلوحة المفاتيح والأسماء العربية وحالة الانتظار وقارئ الشاشة بقدر الإمكان.
7. كرر على هاتف حقيقي عند توفره، وسجل النظام والمتصفح والطراز ولوحة اللمس والحافظة والكسر والسالب والأقواس. يحتاج الهاتف وسيلة وصول محلية مأذونة وشهادة يعالجها المستخدم بنفسه؛ الملف الحالي loopback ولا يُفتح عبر الشبكة تلقائيًا. لا تغير الربط أو مخزن الثقة دون تكليف مناسب.

الوسيط `qa/ph05-math-proxy.mjs` أداة QA خاصة؛ ينقل الرد الفعلي كما هو، ولا يستبدل المحرك. قاعدة التجربة تحوي أربع مسائل اصطناعية موسومة `integration_fixture_not_human_review`. لا توجد مراجعة محتوى بشرية أو حلول ضمن bundle؛ answer_spec يبقى خادميًا. جميع الأسرار داخل `.local` المهمل من Git.

لإيقاف البيئة الخاصة دون المساس بالمشروعات الأخرى، استخدم `prefix` و`envFile` الواردين في `.local/ph05-local.json`:

```powershell
$ph05 = Get-Content -LiteralPath .local/ph05-local.json | ConvertFrom-Json
docker compose -p $ph05.prefix --env-file $ph05.envFile -f compose.ph05.yaml stop
```

قاعدة PostgreSQL هنا tmpfs؛ إيقافها يفقد بيانات هذه التجربة المؤقتة. التشغيل التالي يعيد fixture. تُركت البيئة تعمل عند التسليم للمتابعة التي أجّلها المالك. لا تحذف volume أو قاعدة المشروع الأساسية.

## قرارات التنفيذ وحدوده

تجمع `verification_reports` نتائج الحواف تحت لقطة revision ومجموعة step-version IDs، مع حجز idempotency له مهلة. تُجرى نداءات الشبكة خارج المعاملة؛ الحفظ يعيد فحص الملكية والنسخ، ويمنع العامل القديم من الكتابة فوق إعادة المحاولة. النتائج المنتهية ثابتة، والتعديل يبطل كل مشتقات revision السابقة بصورة محافظة. هذه مواءمة داخلية لـ11/12، ولا تغيير لمسارات API أو JSON أو AST أو نطاق الرياضيات.

مهلة التحقق الكلي 20000ms ونداء المحرك 1500ms ومعدل تجربة التكامل 10000/60s وbootstrap=120s إعدادات صريحة لهذه التجربة؛ ليست سياسة أداء أو عتبة قبول نهائية. يبقى اعتماد المحرر DR-007 وحدود موارد المحرك والمحتوى وGolden وتوقيعات GATE-1 معلّقًا. لا PH-06 أو تشخيص/تلميح/تقدم في هذا التسليم.
