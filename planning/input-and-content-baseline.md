## حدود المدخلات للموافقة

| الفئة | القاعدة المستخرجة | أمثلة | التوقع/قيد التفعيل |
|---|---|---|---|
| الأرقام | U+0660–0669 وASCII مقبولان؛ حفظ raw وعرض عربي | `٢س + ٣ = ٧`، `2س + 3 = 7` | قبول التحليل ضمن النطاق، لا حكم صحة تلقائي |
| الإشارات | U+2212 وASCII `-`؛ سالب أحادي/طرح حسب AST | `−٣س + ١٢ = ٠` | لا قلب للإشارة مع اتجاه الصفحة |
| الرموز | `+`، `−/-`، `×/*`، `÷/`، `=`، أقواس | `٢ × س = ٤` | معادلة واحدة ومساواة واحدة |
| الضرب الضمني | معامل ثم س/قوس وفق الأنماط المعلنة | `٢س`، `٢ س`، `٢(س + ٣)` | `٢٣` عدد واحد؛ لا تفسير `٢س٣` أو `س(٢)` صمتًا |
| الكسور | بسط ومقام صحيحان، مقام ثابت غير صفري؛ قسمة خطية على ثابت | `س=١/٢`، `س/٢=٣`، `٢س/٣=٤` | P0 محدود؛ **لا تفعيل واجهة** قبل اختبار قراءة/عرض/نسخ الكسور |
| الالتباس | لا تخمين قبل/بعد القسمة والضرب الضمني | `١/٢س` | syntax_error وطلب أقواس؛ `(١/٢)س` يراجع ضمن قواعد الضرب الصريحة |
| خارج النطاق | مقام متغير، دوال، أسس، متغير آخر، عشرية، جذور، متعدد المتغيرات | `١/س`، `جا(٣٠°)`، `س²`، `x`، `٣٫٥` | unsupported حسب مالك التصنيف؛ لا تحويل x→س |
| بناء غير صالح | أقواس ناقصة، سلاسل مساواة أو صيغة ناقصة | `س=٢=٣` | syntax_error مع span بوحدة Unicode code points |
| ثابت/منحل | all_reals/empty ضمن اختبارات المحرك | `٠س+٢=٢`، `٠=١` | guard تقني؛ لا نشر كبنك تعليمي ذي حل وحيد |
| موارد | قيود طول/عمق/حجم/مهلة خادمية | مقترحات `10` §15.3 | حد 256 في العقد الحالي، وبقية حدود التشغيل تحتاج قياسًا؛ لا ادعاء إثبات أداء |

يحفظ النظام raw وAST والعرض منفصلة. المعنى والمجال الحقيقي ومجموعتا الحل هما معيار التحقق. LLM لا يحسم الصحة، وحالات syntax_error/unsupported/inconclusive/service_error لا تسجل ضعفًا مفاهيميًا.
