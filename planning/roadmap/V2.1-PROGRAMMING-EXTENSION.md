# V2.1 — إضافة تعليم البرمجة إلى خُطوة AI

**اسم المهمة للوكيل:** `DEV-07 — Intro to Programming`  
**الهدف:** مسار تعلم برمجة للمبتدئين: شرح عربي، والكود باللغة الإنجليزية، وتنفيذ تمارين آمن بنتائج قابلة للتحقق.

## 1. نطاق المرحلة الأولى

**لغة أولى: Python فقط.** الدروس:

1. طباعة النصوص والأرقام `print`.
2. المتغيرات والأنواع الأساسية.
3. العمليات الحسابية.
4. الشروط `if/else`.
5. التكرار `for/while`.
6. الدوال البسيطة `def`.

نستهدف 15–25 تمرينًا قصيرة مع اختبارات نموذجية، ولا نضيف C++ أو JavaScript أو مسابقات برمجية متعددة اللغات في هذا الإصدار.

## 2. تجربة الطالب

يفتح درسًا بالعربية، يقرأ مثال Python، ثم يكتب حله في محرر كود بالإنجليزية ويضغط «تشغيل». يرى الناتج أو الخطأ، ثم يضغط «تحقق من الحل» فتشغّل الخدمة اختبارات التمرين وتعرض عدد الحالات الناجحة. يستطيع طلب تلميح عربي من Gemini بناءً على خطأ محدود منقّح، دون كشف الاختبارات السرية أو الحل المرجعي.

## 3. قاعدة تقنية لا يمكن تجاوزها

**ممنوع تشغيل كود الطالب مباشرة داخل عملية NestJS أو خادم PostgreSQL أو خدمة SymPy.**

اختر طريقة خفيفة لكن معزولة:

- مفضل: خدمة Judge0 CE مهيأة بعزل موارد، أو مزود Runner موثوق مع API خلف NestJS.
- بديل: خدمة runner مستقلة تستخدم sandbox حقيقيًا بحدود CPU/ذاكرة/وقت/مخرجات، وتمنع الشبكة وامتيازات المضيف.
- لا تفتح Docker socket أو ملفات المضيف لحاوية الطالب، ولا تتعامل مع `child_process.exec` على خادم API باعتباره Sandbox.

يمكن تشغيل واجهة الدروس قبل تهيئة Runner، لكن **لا تعتبر المرحلة مكتملة** حتى ينجح تشغيل كود الطالب بأمان.

## 4. المهام

### DEV-071 — محتوى مادة البرمجة

- مادة `programming` ووحدة `python_basics` تستخدم نظام المناهج والإصدارات من V1.3.
- مهارات `variables`, `conditions`, `loops`, `functions` وأمثلة عربية.
- لكل تمرين: وصف عربي، بداية كود إن لزم، حالات اختبار علنية ومخفية، ونموذج حل مرجعي مراجع.
- لا تخزن مفاتيح الحل أو hidden tests في React أو الـAPI العامة.

### DEV-072 — محرر كود React

- محرر بسيط: textarea محسنة أو CodeMirror/Monaco **واحد فقط** بحسب الوزن والأداء وحاجة المشروع.
- الحفاظ على المسافات البادئة، tab، الأسطر، النسخ واللصق، وواجهة LTR للكود وسط صفحات عربية RTL.
- زران واضحان: «تشغيل تجريبي» و«تسليم الحل»؛ حالات تحميل ووقت تجاوز المهلة وأخطاء Python.
- لا تستدعِ Runner أو Gemini مباشرة من المتصفح.

### DEV-073 — خدمة تشغيل محدودة

- API خلف NestJS ترسل الكود إلى Runner مع معرف اللغة والإصدار وحد الموارد.
- حدود مبدئية قابلة للضبط: مهلة ~2 ثوانٍ لكل تنفيذ، ذاكرة ~128 MiB، حد مخرجات ~64 KiB؛ اضبطها وفق قدرات Runner الموثقة قبل تفعيلها.
- تشغيل دون اتصال شبكة خارجي، دون امتيازات، دون ملفات مضيف، ودون بيانات اعتماد حقيقية.
- سجّل `queued/running/succeeded/compile_error/runtime_error/timeout/resource_limit` بحسب أداة Runner.
- rate limit لكل مستخدم واحتساب حدود يومية بسيطة لمنع الاستهلاك المفرط.

### DEV-074 — التحقق من حلول التمارين

- تحقق آلي من خلال اختبارات حالات دخل/خرج أو دوال محددة؛ بعض المسائل تفحص stdout وأخرى استدعاء function.
- لا تعتمد على تطابق نص الكود مع الحل المرجعي؛ تقبل أساليب صحيحة مختلفة.
- اجعل مجموعة اختبارات المعلم مخفية عن الطالب، وسجّل النتائج المجملة فقط.
- نجاح كل الاختبارات المحددة هو مصدر verdict؛ Gemini ليس هو المصحح النهائي.

### DEV-075 — الذكاء التعليمي في البرمجة

- يقرأ NestJS نوع الخطأ أو حالات الاختبار المسموح كشفها، ويعطي Gemini سياقًا منقحًا لتلميح عربي.
- خذ بعين الاعتبار عدم إرسال كود طالب حقيقي إلى مزود خارجي إلا وفق سياسة الخصوصية وموافقة الاستخدام ذات الصلة.
- H1 يوجه إلى الفكرة؛ H2 يوضح مفهومًا؛ H3 يقترح خطوة تصحيح؛ H4 يساعد بشرح مراجع عند السماح.
- لا يكشف Gemini كامل الحل أو hidden tests، ولا يمنح نجاحًا لتفسير لغوي جميل.

### DEV-076 — التقدم وسجل المحاولات

- اربط محاولات الكود بمهارة البرمجة وإصدار التمرين، مع حفظ النص الخام وتاريخ التنفيذ بشكل محدود.
- حالة المستخدم: محاولة جديدة، فشلت حالة، نجحت كل الاختبارات، نجح بمساعدة، دليل مستقل.
- اعرض التقدم إلى جانب الرياضيات والفيزياء دون دمج معايير الحكم المختلفة.

### DEV-077 — لوحة المعلم

- إنشاء تمرين Python وإدخال حالات اختبار والتحقق منه في Sandbox قبل النشر.
- عرض نتيجة اختبار علني/مخفي للمحتوى مع اعتماد draft/publish.
- لا يمكن نشر تمرين لا تنجح اختبارات الحل المرجعي فيه.

### DEV-078 — اختبارات أساسية

- 10 حالات إدخال صحيحة ومسائل ناجحة، وحالات SyntaxError وRuntimeError وTimeout.
- اختبار حل بديل ينجح رغم اختلاف الكود عن الحل النموذجي.
- اختبار فصل المستخدمين وسرية hidden tests.
- اختبار محاولة قراءة ملفات المضيف أو فتح شبكة أو استهلاك موارد: يجب أن يوقفها Sandbox دون تهديد خادم NestJS.
- اختبار أن تعطل Runner لا يضيع نص الطالب، وأن فشل Gemini لا يحول النتيجة إلى نجاح زائف.

## 5. تعريف الاكتمال

- الطالب يستطيع فتح درس Python وكتابة كود وتشغيله وتسليمه ورؤية النتيجة والتلميحات العربية.
- تشغيل الكود معزول فعليًا، والاختبارات المخفية لا تُكشف في المتصفح.
- يستطيع المعلم نشر تمرين جديد بعد اختبار صحته.
- يظل خادم الرياضيات منفصلًا، ولا تُغيّر أحكامه أو عقوده بسبب دعم البرمجة.

- تقرير `qa-reports/DEV-V2.1-PROGRAMMING-DELIVERY.md` مع مثال مسألة قابلة للتغيير واختبار محاولة ضارة آمنة.
