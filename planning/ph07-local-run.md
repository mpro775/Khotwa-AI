## التشغيل المنفذ

```powershell

npm run dev:ph07
```

الأول يشغل 11 مجموعة خفيفة، ومنها عشر وحدات خاصة بالتلميحات. الثاني يبني صورة حديثة، وينشئ شبكة داخلية وPostgreSQL 17.6 مؤقتة وPython/SymPy حقيقيًا، ثم يختبر NestJS عبر HTTP. يزيل موارده الموسومة فقط. لا حمل ثقيل أو استدعاء مزود خارجي. سبع migrations و26 جدول أعمال؛ يشمل الفحص rollback لدلتا PH-07 مع بقاء PH-06 ثم replay كاملًا.

`dev:ph07` يشغل compose.ph07.yaml كمشروع مستقل. العنوان [https://localhost:8445/](https://localhost:8445/)؛ metadata غير السرية في `.local/ph07-local.json`. المنفذ 127.0.0.1 فقط؛ API وPython وDB خاصة، وDB في tmpfs. لا ترحيل أو seed لقاعدة Compose الأساسية أو تعديل مشاريع PH-05/06 القائمة. لإيقاف هذا الملف فقط:

```powershell

docker compose --project-name $ph07Metadata.prefix --env-file $ph07Metadata.envFile -f compose.ph07.yaml stop
```

قاعدة tmpfs مؤقتة؛ إيقاف حاويتها يفقد بيانات الاختبار. `dev:ph07` يعيد بناء بيئة الاختبار وبذورها. لا تستخدم أوامر reset/down الخاصة بـQA على قاعدة أخرى.

## القرار والمحتوى

رد المالك: **«لا يوجد مزود معتمد بعد؛ أبقِ الاتصال الخارجي معطلًا»**. DR-008 يبقى pending للمزود والنموذج والسعر وشروط البيانات. `AI_ENABLED=false`؛ تفعيل true يوقف الإقلاع صراحة. لا SDK أو adapter خارجي أو مفاتيح أو استدلال LLM فعلي. AiTutorPort اختُبر عبر بديل HTTP خاص محليًا، ونوعه test_double ظاهر في audit؛ actualLlmUsed=false دائمًا في هذا التسليم.

الكتالوج المحلي أربع مسائل اصطناعية، وستة أنماط وثمانية أسئلة و26 قالب تلميح draft. لا توقيع مراجع بشري. generationSource=manual يصف أصل fixture المؤلف، ولا يعني اعتماد المختص أو نتيجة LLM. لا reviewed_template أو llm_validated من هذه التجربة. التفعيل يتطلب أعلام PH04/05/06/07 والبيئة والصفوف الاصطناعية؛ الافتراضي PH07_API_ENABLED=false. خارج المحتوى الصالح يرد 503 آمن؛ لا بديل مولّد غير متحقق.

## السياسة والحفظ

- H0 بلا مساعدة؛ أول طلب صريح H1 ثم H2/H3. لا H4 تلقائيًا. الحل الكامل متاح في main/remediation بتأكيد مستقل، حتى قبل كتابة أول خطوة، ولا يكمل المحاولة بمجرد عرضه.
- كل H1+ يسجل عدم أهلية الاستقلال؛ H4 يسجل مشاهدة الحل. الحالة تبقى بعد التعديل وإعادة التحميل وتعطيل علم التلميحات. migration 0007 تحفظ assisted_completed القديمة دون اختلاق مستوى مجهول أو افتراض H4.
- probe/transfer يحجبان المساعدة. سؤال تأكيدي مفتوح يحجب التلميح، والمساعدة السابقة تمنع استعمال جواب لاحق كدليل مستقل. تحويل وضع النقل أو تعيين علاج/نقل أو حساب إتقان يعود إلى PH-08/09، ولم ينفذ هنا.
- الحدث مثبت إلى problem/attempt revision ومصدر الخطوة والتحقق والتشخيص والقالب والسياسة والموجه. capture/call/commit ينتظر الخدمات خارج المعاملة، ثم يعيد فحص السياق؛ الرد المتأخر لا يحدث الحالة. إعادة المفتاح نفسه لا تصعد المستوى مرتين.
- H3 ذو الحساب الجزئي يمرر assertions إلى Python؛ H4 يفحص السلسلة والحل المعزول والتعويض. هذه صحة رياضية وليست مراجعة تربوية للقالب. لا تعديل لحكم المحرك أو نص الطالب أو توقعات Golden.

## حدود التجربة

إعدادات PH07 الصريحة في runner الحاويات والملف المحلي: REQUEST_TIMEOUT_MS=20000، AI_TIMEOUT_MS=500، MAX_INPUT_BYTES=8192، MAX_OUTPUT_TOKENS=256، GUEST_CALLS=100، GLOBAL_CALLS=1000، GUEST_COST_UNITS=1000، GLOBAL_COST_UNITS=10000، MAX_PARALLEL=2. جميع الأسماء تبدأ بـPH07_. القيم حدود اختبار وليست عتبات اعتماد نهائية أو تسعير مزود. قد تختبر الحالات حدودًا أصغر داخل العملية.

الحجز ذري لكل guest/day وglobal/day، بلا إعادة محاولة AI خفية أو ردّ رصيد يوهم أن الفشل مجاني. وحدات synthetic_reservation_units تجريبية؛ جمع دفتر الضيف والعالمي يكرر احتساب الاستدعاء نفسه محاسبيًا. تشغيل التكامل سجل 24 اتصالًا ببديل الاختبار، وصفر استدلالات/اتصالات خارجية؛ لا تكلفة نقدية مقاسة. التدقيق metadata فقط: الإصدارات والحدود والزمن وسبب الرفض والرموز المبلغ عنها عند توفرها، بلا prompt/raw/استجابة خام/مفاتيح.

السياق allowlist من قالب المستوى الحالي ووصف ثابت ومهارة، بلا هوية أو raw أو تاريخ أو مفاتيح الحل أو حل H4 أو مادة نقل. schema صارم ثم مطابقة لصيغ مؤلفة مسموحة فقط؛ لا يفوض النموذج بالحساب. اسم reviewedHintTextAr الداخلي من تصميم السياق لا يغير حالة draft للمحتوى.

## فحص المتصفح والأجهزة المتبقي

شهادة localhost ذاتية التوقيع تحت `.local/ph07-tls` دون تغيير مخزن الثقة. فاحص HTTPS يثبت هذه الشهادة لهذا الطلب مع إبقاء التحقق فعالًا؛ نجاحه ليس اختبار متصفح. الخطوة اليدوية لـChrome مؤجلة سابقًا بأمر المالك والهاتف غير متاح. لا تفاعل PH-07 أو صور/تسجيلات حاسوب أو هاتف في هذا التسليم؛ [الحالة](../qa-reports/ph07-browser-checks.json).

عند استكمال الخطوة اليدوية، يسجل QA الجهاز والمتصفح والإصدار والوقت والنسخة، ثم:

1. ابدأ ضيفًا واختر `٢(س + ٣) = ١٠` من المحتوى الموسوم اصطناعيًا. احفظ `٢س + ٣ = ١٠` وتحقق؛ افصل الحكم عن السبب المحتمل وعن التلميح.
2. اطلب H1 ثم H2 ثم H3. افحص RTL والقراءة ولوحة المفاتيح وقارئ الشاشة والنسخ، وأن الطلب الرابع لا يكشف H4.
3. افتح تحذير الحل؛ لا كشف قبل مربع التأكيد والزر الصريح. افحص خطوات H4 بصريًا واتجاه س والأرقام والكسور. كرر H4 قبل كتابة خطوة في محاولة جديدة.
4. صحح الحل وأعد التحقق؛ يجب أن يظهر الاكتمال بمساعدة. أعد تحميل الصفحة ثم عدل خطوة؛ لا يرجع دليل الاستقلال، ولا تعرض بطاقة قديمة بعد التعديل.
5. اختبر التأخير وإعادة الطلب، ونصًا غير مدعوم/قوسًا ناقصًا؛ تبقى المسودة والحكم محفوظين، ولا تعرض رسالة تعثر مفاهيمي من تعذر الخدمة.
6. اطلب سؤالًا تأكيديًا قبل المساعدة؛ لا يتاح تلميح وهو مفتوح. بعد المساعدة لا يعامل جواب لاحق كدليل مستقل. لا تفترض وجود واجهة نقل/علاج في PH-07.
7. أعد الإدخال والحافظة واللمس والعرض الضيق على هاتف فعلي عند توفره، واحفظ صورًا أو تسجيلًا حقيقيًا؛ لا تسجل محاكاة الحاسوب هاتفًا.
