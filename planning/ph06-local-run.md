# تشغيل PH-06 وفحصها

> 2026-11-04 / Asia/Riyadh. بيئة اصطناعية للمراجعة فقط. GATE-1 محجوبة؛ لا محتوى تربوي أو Golden معتمدان من هذا التشغيل.

```powershell
npm run verify:ph06
npm run verify:ph06:container
npm run dev:ph06
node qa/ph06-https-probe.mjs
```

`verify:ph06` يشغل عشر مجموعات خفيفة: العقد والتنسيق وlint والأنواع والبناء ووحدات API والتشخيص والمحرر والعميل وsmoke. `test:diagnosis` منفردًا يحتاج build API أولًا. لا dependencies جديدة أو ترقية مكتبات.

فحص الحاويات يستعمل PostgreSQL 17.6 وشبكة داخلية عشوائية وقاعدة tmpfs، بلا منافذ مضيف أو بيانات حقيقية. يرحّل خمس migrations، يفحص rollback لـPH-06 مع بقاء PH-05، ثم replay، ويشغل NestJS وPython الحقيقيين. Python لا يتلقى أسرار DB أو الضيف. يحذف الفاحص موارده الموسومة فقط ويحفظ الأدلة. `--skip-build` للتكرار المستهدف إذا طابق المصدر المترجم الصورة؛ الفحص النهائي يتضمن بناءً حديثًا.

**المتوقع حاليًا أن يفشل أمر الحاويات في مقارنة Golden الدقيقة** بسبب [DATASET-ISSUE-PH06-01](ph06-dataset-issue.md). اختبارات السلوك مستقلة عن مقارنة المرجع؛ الأرقام التفصيلية في [الحالة](ph06-status.json) و[الخرج](../qa-reports/ph06-container.json). لا تتجاهل exit code أو تحول الفشل إلى نجاح. CI أضيف إليه الفحص نفسه دون allow-failure؛ CI البعيد لم يُشغّل في هذا التسليم.

`dev:ph06` يبني `compose.ph06.yaml` كمشروع منفصل عن PH-01 وPH-05. العنوان الحالي https://localhost:8444/، والتفاصيل غير السرية في `.local/ph06-local.json`. المنفذ مربوط بـ127.0.0.1 فقط؛ API وPython وPostgreSQL خاصة. قاعدة التجربة مؤقتة، والكتالوج أربع مسائل اختبار مع ست مهارات/أنماط وثمانية أسئلة **draft اصطناعية غير مراجعة**. لا يعيد التشغيل وسمها reviewed.

التفعيل يتطلب `PH04_API_ENABLED=true` و`PH05_API_ENABLED=true` و`PH06_API_ENABLED=true` مع `KHOTWA_SYNTHETIC_DATA=true`. تشغيل PH-06 مع Store غير اصطناعية يرفضه الخادم. يتحقق أيضًا من الجلسة والكتالوج والقالب الاصطناعيين داخل المعاملة؛ علم في الواجهة لا يمنح هذه الصفة. يظل PH06 false في الإعداد الافتراضي وCompose الأساسي، ولا يرحّل أو يزرع قاعدة المشروع الأساسية.

مهلة التحقق الكلي 20000ms. مهلة Python في runner الحاويات 1500ms وفي الملف التفاعلي 15000ms لتجربة تأخير الرد؛ bootstrap=120s. معدل runner=10000/60s، والملف التفاعلي=1000/60s. قيم تجربة صريحة، وليست عتبات قبول نهائية. لا تشغيل حمل ثقيل أو تقييم تربوي أو بيانات قُصّر.

## متابعة الفحص التفاعلي

يولد التشغيل شهادة localhost ذاتية التوقيع لمدة سبعة أيام تحت `.local/ph06-tls` دون تغيير مخزن الثقة. يتحقق فاحص HTTPS من الشهادة لهذا الطلب وحده؛ لا يعطّل TLS. فحص Chrome التفاعلي كان مؤجلًا بقرار المالك في PH-05، والهاتف غير متاح؛ لم يُعد طلب الخطوة اليدوية، ولم تُختبر واجهة PH-06 فعليًا أو تلتقط صور لها. يتولى المستخدم أي تحذير شهادة بنفسه وفق حد Computer Use السابق.

عند استكمال الخطوة اليدوية، سجّل الجهاز والمتصفح والإصدار ووقت/run_id وصورًا فعلية، ثم:

1. ابدأ جلسة ضيف واختر مسألة `٢(س + ٣) = ١٠` من الكتالوج الموسوم اصطناعيًا. احفظ `٢س + ٣ = ١٠` وتحقق من السلسلة؛ افصل حكم عدم التكافؤ عن بطاقة «سبب محتمل» والمهارة ذات القرينة.
2. اطلب السؤال. تأكد من غياب الحل أو مؤشر الخيار الصحيح، ومن وجود خيار «لا أدري». أجب مرة باختيار متسق مع الإغفال في محاولة، وباختيار صحيح في محاولة أخرى؛ الصحيح يناقض فرضية الخطأ ولا يثبت ضعفًا دائمًا.
3. اختبر «لا أدري»: يجب أن تبقى النتيجة unresolved، دون درجة أو تحديث مهارة. النص الحر متاح في العقد، ويخزّن unverified عند عدم وجود تحقق لغوي معتمد؛ لا تخمين من LLM.
4. حرر خطوة أثناء انتظار السؤال أو الإجابة؛ يجب أن تختفي البطاقة فورًا وألا يعيد الرد المتأخر عرضها. احفظ التعديل ثم تحقق؛ لا تعرض فرضية الإصدار القديم. فحص Node الحقيقي يثبت الحماية الخادمية، ووحدة العميل تثبت رفض السياقات المخالفة؛ لا يحلان محل فحص التفاعل.
5. أعد الطلب بنفس المفتاح وفحص السلسلة مرة أخرى: لا جواب/سؤال إضافي مستقل لنفس revision والسياسة. إعادة الصفحة تستعيد المحاولة والفرضية الحالية من الخادم.
6. افحص لوحة المفاتيح وتسميات radio/fieldset وحالة الانتظار والرسائل العربية وRTL والنسخ واللصق دون تغيير النص الخام. كرر على هاتف فعلي عند توفره؛ العرض الضيق ليس هاتفًا فعليًا، والملف الحالي لا ينشر منفذًا للشبكة.

لا PH-07 أو تلميح أو علاج أو نقل أو تقدم مهارة من nextAction=continue. لا تتحول إجابة السؤال إلى حل مستقل. بعد الفحص يلزم مختص المادة والتربية وQA لحسم المرجع والقوالب والسياسة، ومراجعة الواجهة/NestJS واعتماد GATE-1 وفق شروطها.

لإيقاف هذا الملف فقط:

```powershell
$ph06 = Get-Content -LiteralPath .local/ph06-local.json | ConvertFrom-Json
docker compose -p $ph06.prefix --env-file $ph06.envFile -f compose.ph06.yaml stop
```

توقف DB يفقد بيانات tmpfs الخاصة بهذه التجربة. لا تستعمل أوامر حذف عامة أو تغيّر موارد PH-01/05. تُرك الملف يعمل للمراجعة؛ الأسرار في `.local` المهمل من Git ولا تدخل التقارير.
