## المحتوى والحفظ

البنك **draft اصطناعي غير مراجع بشريًا**: ستة جذور تعليمية، لكل منها تدريبان وثلاث مسائل نقل، بإجمالي 36 مسألة و36 pairing. كل جواب مرجعي خاص فُحص بـcheck-final في Python الحقيقي قبل نشر release الاختبارية؛ صحة الحل لا تعني مراجعة لغوية/تربوية. 58 قالب تلميح draft، ولا ينسب إليها توقيع مراجع أو مصدر llm_validated. لا تستخدم هذا البنك مع متعلمين حقيقيين قبل اعتماده.

المسألة الأصلية وتحليلها والمعنى والعرض منفصلة كما في PH-05. الربط يثبت skill/release/notation والصعوبة والمراجعة وسبب الاختلاف البنيوي المؤلف ونسخ المحتوى. لا مولد مسائل عشوائي. ملكية الحلقة والإسناد والمحاولة خادمية، وUUID لا يمنح وصولًا. النقل لا يدخل الكتالوج؛ لا يقرأه إلا مالك إسناده بعد جاهزية الحلقة، ولا يصل answer_spec إلى المتصفح.

التعرّض append-only على مستوى الضيف عبر جلسات التعلم: النسخة والعائلة وبصمة النص، مع استبعاد المحاولات السابقة ونصوص التلميحات والأسئلة التأكيدية المقدمة. عائلات المحتوى وسبب الاختلاف metadata مؤلفة تحتاج مراجعة بشرية؛ ليست خوارزمية تثبت تلقائيًا أن سؤالين متباعدان تربويًا. يتوقف الاختيار إذا لم يبق مرشح صالح.

أضيفت learning_episodes وlearning_assignments وcontent_pairings وcontent_exposures وskill_evidence، وحقل learning_family للمسألة، بترحيل 0008 داخلي لا ينشر محتوى. الأحداث والتعرض ثابتان؛ إبطال المشتقات يحفظ التاريخ ولا يمحو الانكشاف. تعديل الأصل يلغي الحلقة وإسناداتها؛ تعديل العلاج يبطل النقل المعتمد عليه. الردود القديمة والمفاتيح المتكررة لا تنشئ حلقات/محاولات مضاعفة. إعادة طلب إسناد له محاولة تعيد المحاولة نفسها.

## قرارات التنفيذ داخل العقد القائم

- عمليات remediation وtransfer وlearning-episodes ومصدر assignment وparentEpisodeId تستخدم OpenAPI القائم. progress هنا إسقاط محدود لخدمة دليل رحلة PH-08؛ لا لوحة معلم أو تجميعات/خوارزمية إتقان PH-09.
- «أحتاج مساعدة وأوافق على مغادرة القياس» في الواجهة يستخدم HintInput القائم. next_hint أو show_full_solution المؤكد طلب صريح؛ يحفظ الخادم الخروج داخل حجز الطلب وقبل كشف المحتوى. لا إعادة استقلال بعد ذلك، حتى مع إعادة التحميل أو التعديل. H4 غير المؤكد لا يكشف حلًا، والطلب المرفوض قبل قبوله لا يسجل تلميحًا مختلقًا.
- Attempt.kind يبقى transfer لتتبع الأصل، وassistancePolicy يصبح guided مع measurement_exited_at؛ لا حقل أو مسار جديد. فشل المعالجة بعد حجز الخروج لا يعيد أهلية القياس.
- أثناء النقل تحجب **جميع الاستجابات العامة** مجموعات الحل والشاهد العددي والسبب التعليمي الآلي: evidence=null وdiagnosisCandidate=null وفق nullable في العقد، مع إبقاء MathStatus كما هو. يشمل التحقق وتكراره وتفاصيله وقراءة/قائمة المحاولات، حتى عند تعطيل علم PH-08. الدليل الكامل محفوظ داخليًا؛ لا سؤال تأكيدي تعليمي أثناء قياس النقل.
- دليل إيجابي مستقل يتطلب إكمال سلسلة حالية صحيحة، وإسناد transfer مستقلًا وجديدًا، وعدم مساعدة/تعرّض. التسريب اللاحق يسقط الدليل الحالي أيضًا، دون تغيير تاريخه. الجواب الصحيح بعد حافة خاطئة لا يكفي.
- نشاط remediation يقاس بوصفه **تدريبًا موجّهًا**؛ assistedPracticeCount يعد اكتمال هذا السياق أو نقلًا خرج إلى التعلم، وليس عدد التلميحات أو ادعاء أن H1 استعمل حتمًا. assistance_snapshot يحفظ H0…H4 ومشاهدة الحل فعليًا؛ لا تخمين لمستوى غير مستعمل.
- التقدم يحصي آخر تقرير حالي لكل محاولة/مراجعة/سياق مساعدة. الأولوية لدليل نقل صالح، ثم حاجة متابعة مثبتة لم تُبطل، ثم تدريب موجّه، وإلا not_assessed. التعذر لا يخصم دليلًا صالحًا آخر ولا يعني صفرًا. لا نسبة أو إتقان دائم.
- زر «أتوقف هنا» يوقف التفاعل محليًا ويحفظ العمل، ولا يدعي إرسال أمر إلغاء أو تغيير Attempt.status؛ لا عملية pause/stop عامة في العقد الحالي. الاستئناف يعيد الحلقة من الخادم، ولا يولد نجاحًا بسبب التوقف.

## الفحص التفاعلي المتبقي

لم يُنفذ Chrome أو هاتف فعلي أو صور/تسجيلات PH-08. الهاتف غير متاح، والخطوة اليدوية للشهادة مؤجلة سابقًا بقرار المالك. نجاح HTTPS البرمجي يثبت TLS مع شهادة مثبتة لهذا الطلب والتحقق فعالًا؛ لا يغير مخزن الثقة ولا يحل محل التفاعل المرئي.

عند استكمال الخطوة اليدوية وتوفر الجهاز، يسجل QA نوع الجهاز والمتصفح وإصداره ووقت الفحص والنسخة، ثم:

1. اختر المسألة الاصطناعية `٢(س + ٣) = ١٠`، واكتب `٢س + ٣ = ١٠` وتحقق. افصل الحكم عن السبب المحتمل، وأجب السؤال المفتوح قبل طلب المساعدة أو العلاج.
2. جرّب H1…H3 ثم تأكيد H4. ابدأ التدريب من الزر، وافتح الإسناد؛ لا يظهر النقل قبل إتمام التدريب، ولا تستبدل مسودتك غير المحفوظة بعودة طلب متأخر.
3. اكتب حل التدريب بنفسك أو اطلب مساعدة مسجلة. أكمل التحقق، ثم اطلب نقلًا جديدًا. افحص الفرق البنيوي واتجاه الأرقام/س/السالب والأقواس والكسور إن ظهرت.
4. أثناء النقل، راجع الاستجابة والواجهة: الحكم ظاهر ومجموعات الحل/الشواهد والحل المرجعي محجوبة. إكمال صحيح دون مساعدة يعطي دليلًا محدودًا، لا «أتقنت نهائيًا».
5. في محاولة نقل أخرى اختر مغادرة القياس ثم H1 أو H4 المؤكد؛ لا يرجع الاستقلال بعد إعادة التحميل أو تعديل الخطوة، وتأتي مسألة جديدة عند إعادة القياس.
6. اختبر خطأ مثبتًا ثم تدريبًا آخر، ونفاد المحتوى/حد النشاط، وزر التوقف والاستئناف. جرّب unsupported وقوسًا ناقصًا وتعطل الخدمة دون عقوبة مفاهيمية.
7. عدّل الأصل أو العلاج بعد إسناد النقل؛ يجب حجب الإسناد والدليل المتأثرين فورًا. افحص التكرار والتأخير والتنقل بلوحة المفاتيح وقارئ الشاشة والحافظة واللمس على هاتف فعلي عند توفره.
8. احفظ صورًا أو تسجيلات فعلية بنتائجها؛ لا تنقل صور PH-02 كدليل جديد. [حالة الأجهزة](../qa-reports/ph08-browser-checks.json) و[تقرير التسليم](../qa-reports/ph08-delivery.md).
