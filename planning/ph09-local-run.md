## مصدر تقدم الطالب

ProgressService يقرأ view من skill_evidence الحالية، ويثبت المصدر/المراجعة/المساعدة/الحلقة/الإسناد/المحتوى/المحرك والسياسة، ويمنع تكرار المصدر الواحد. لا cache مستقل يحتاج تصديق الواجهة. سحب المحتوى أو تغيير سياسة الإسناد أو تعديل المصدر أو تعرض لاحق يحجب الدليل الإيجابي المتأثر مع إبقاء التاريخ. تقدم الطالب من أحداث التدريب والنقل المؤهلة؛ المسألة الأصلية تبقى في سجل التحقق والتشخيص ولا تُحسب نقلًا مستقلًا لمجرد صحتها.

GET progress وskill detail هما العقد القائم. واجهة الطالب تربط وصف المهارة بمراجعة محاولات الجلسة عبر GET attempts وlearning-episodes القائمتين؛ لا حقول أو endpoints جديدة للأدلة. القائمة paginated، ولا يعني ظهور صف فيها أنه محسوب في العدادات. لا يستنتج المتصفح أهلية الاستقلال أو نسبة إتقان. عند تحرير المسودة يحجب العرض القديم، والردود المتأخرة مقيدة بسياق الجلسة/المكون. لا صفر افتراضي كدرجة لمهارة غير مقاسة.

assistedPracticeCount يحتفظ بدلالة PH-08: إكمال في سياق guided، وليس عدد التلميحات. H0…H4 ومشاهدة الحل محفوظة في اللقطة الفعلية؛ لا تلميح مختلق أو استقلال بعد H4. فشل خدمة لاحق لنفس المدخل لا يمحو حقيقة رياضية صالحة سابقة؛ تعديل المدخل يبطل مشتقاته، وفشل التحقق بعدها لا ينشئ دليل ضعف.

## مصدر لوحة المعلم وعزلها

TeacherDemoService لا يستقبل Store أو اتصال DB أو learningSessionId/attemptId أو مسار مصدر قابلًا للضبط. الحارس العام فقط يفحص GuestCookie. المصدر apps/api/data/teacher-demo.v1.json، موسوم authored_static_synthetic ومثبت بـSHA256 ومخطط صارم وقواعد اتساق؛ الخطأ يمنع تشغيل المصدر، ولا يعود إلى بيانات الضيوف.

الحزمة تحتوي 8 متعلمين افتراضيين و12 محاولة مؤلفة: 8 قابلة للتقييم الرياضي، 4 متعذرة، 3 انتقالات غير متكافئة، 2 نقل مستقل افتراضي، و2 إكمال بعد مساعدة. كل عدد مشتق من rows، وليست هذه نتائج تجربة تعليمية أو نسبًا علمية. ثلاثة أمثلة رياضية مختلفة عن بنك النقل؛ صحتها/عدم تكافئها فحصت في QA عبر Python الحقيقي. السبب التعليمي فرضية مؤلفة والمراجعة البشرية معلقة. لا أسماء أو بريد أو هاتف أو نسخ محاولات ضيوف؛ fake UUIDs لا تحل إلى موارد الكتالوج أو محاولة حقيقية.

كل ضيف صالح يرى الحزمة نفسها. معاملات تبديل المصدر أو تمرير مورد حقيقي ترفض، ولا يمكن استعمال عرض المعلم لقراءة progress لضيف آخر. isSynthetic=true ثابت، ويظهر الوسم وحجم العينة والمصدر في الملخص والتفاصيل. لا دور معلّم فعلي أو حسابات مدارس أو مشاركة حقيقية ضمن P0. مخطط JSON العام لم يتغير؛ حالة 400 للاستعلام غير الموثق في progress تُطابق العقد القائم بدل 422 غير المدرجة سابقًا.

## الاحتفاظ والاختبارات الأمنية

OWN-11 و16 §15 يثبتان سبعة أيام بعد انتهاء الجلسة، لا بعد آخر نشاط. retention-review.ts يحسب read-only أقرب نهاية فعلية معلومة: الانتهاء المطلق أو الخمول أو الإبطال؛ ثم حد أهلية المراجعة بعد سبعة أيام. اختبرت الحدود قبل/عند الموعد والخمول والخروج، واختبر أن logout يبطل الوصول ولا يحذف العمل أو يحيي جلسة. لا endpoint حذف كامل أو TTL job أو تعطيل لمحفزات التاريخ أو وعد بمحو السجلات. **التطهير التشغيلي والنسخ الاحتياطية/الاستعادة ومراجعة الأمن ما زالت معلقة**؛ هذا ليس اختبار حذف فعلي.

حقن Python/AI يتم في عمليات QA الخاصة فقط، عبر HTTP loopback. أوضاع Python 503/timeout/JSON خاطئ وتمرير حقيقي مع حجز رد لاختبار التعديل المتزامن؛ لا منفذ تحكم عام أو علم تعطيل في المنتج. بديل AI اختباري فقط؛ fallback من قوالب draft موسومة manual، أو خطأ مُدار يحفظ العمل. لا استدلال LLM أو تكلفة نقدية.

تعطل npm ci الأول بسبب ECONNRESET. تحققنا من مطابقة ملف القفل والتبعيات مع صورة Linux السابقة واستعملناها في تشغيل تطويري، ثم نجح البناء النهائي **من Dockerfile القياسي** بعد اكتمال طبقة التثبيت. لا مكتبات محدثة أو فحوص مخففة. أدلة المحاولات والاستعادة في تقرير التسليم؛ لا حاجة للمسار المؤقت .local عند التشغيل الطبيعي.

## قائمة الفحص التفاعلي المتبقي

لم ينفذ تفاعل PH-09 على Chrome أو هاتف، ولا صور/تسجيلات. الهاتف غير متاح والخطوة اليدوية للشهادة مؤجلة سابقًا من المالك؛ لا إعادة طلب لها أو تجاوز آلي للتحذير. HTTPS البرمجي يستعمل الشهادة المثبتة لهذا الطلب والتحقق فعال، دون تغيير مخزن الثقة؛ ليس فحص متصفح مرئيًا.

عند استكمال الخطوة اليدوية وتوفر الجهاز، يسجل QA النسخة والجهاز والمتصفح والوقت ثم:

1. ابدأ جلسة ضيف؛ افتح ملخص المهارات قبل نشاط مؤهل، وتحقق من «لم يتوفر دليل» دون شريط 0% أو حكم إخفاق.
2. نفذ تدريبًا بمساعدة ونقلًا مستقلاً، وافتح «راجع مصدر هذا الوصف». راجع السؤال والخطوات وحكم المحرك وحدود العدادات، ثم pagination. تأكد من عدم افتراض أن كل صف محسوب.
3. عدل المسودة وأعد الحفظ/التحقق، وجرّب التأخير وإعادة التحميل. لا تعود بطاقة قديمة بعد التحرير، ولا يفقد المحرر النص بسبب تعذر تحديث الملخص.
4. افتح /demo/teacher؛ يجب أن يبقى وسم الاصطناعية واضحًا أثناء التحميل والفشل والتفاصيل. راجع 8/12 ومصدر كل كرت وغياب نسب إتقان أو أسماء حقيقية.
5. افتح الأمثلة الثلاثة وافحص س والأرقام والإشارات والأقواس وRTL والنسخ والتنقل بلوحة المفاتيح وقارئ الشاشة. لا تتحول الفرضية إلى تشخيص جازم.
6. من ضيف آخر حاول رابط جلسة/مهارة/محاولة أولى؛ يجب الرفض دون كشف. لا زر أو فلتر يبدل Teacher Demo إلى بيانات فعلية.
7. اختبر العرض الضيق واللمس على هاتف فعلي عند توفره، ثم احفظ صورًا أو فيديو فعليًا. لا تستعمل صور PH-02 كأدلة جديدة أو محاكاة هاتف كاختبار جهاز.
