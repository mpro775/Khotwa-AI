# PH-11 — مسودة العرض والتسليم

2026-11-06 / Asia/Riyadh. **إعداد فقط؛ لا اعتماد GATE-4 أو نشر أو تسليم نهائي.**

## تشغيل وإيقاف واستعادة البيئة المحلية

المتطلبات: Docker Desktop وNode/npm حسب package.json. من جذر المستودع:

```powershell
node tools/serve-mvp.mjs
docker compose -f compose.mvp.yaml --env-file .local/mvp-local.env stop
node tools/serve-mvp.mjs --skip-build
node qa/mvp-https-probe.mjs
node tools/check-mvp-security.mjs
```

العرض افتراضيًا https://localhost:8448/؛ العنوان الفعلي في `.local/mvp-local.json`. الشهادة محلية ذاتية التوقيع؛ لا تغيير لمخزن الثقة أو تعطيل تحقق TLS. قبول Chrome للشهادة خطوة يدوية للمالك إذا ظهرت شاشة الأمان. أداة HTTPS تثبت CA لعمليتها فقط، ولا تثبت قبول Chrome.

التهيئة تنشئ مشروع Docker مستقلًا وقاعدة **عرض اصطناعية دائمة** وتطبق migrations على هذه القاعدة الجديدة فقط. الأسرار تولد في `.local/mvp-local.env` المتجاهل من Git؛ لا تشاركه أو تستخدم إعداد قاعدة حقيقية. لا حاجة إلى مفتاح Gemini؛ الاتصال الخارجي معطل والسقف السابق مستنفد.

الإيقاف يحفظ الحجم والمفاتيح؛ الاستئناف يعيد البيئة نفسها ويتحقق من عدم تكرار إدخال المحتوى. لا تحذف ملف البيئة أو تستخدم `down -v` عند الحاجة إلى البيانات؛ الملف يحفظ مفاتيح الجلسات وكلمة مرور الحجم. هذه ليست نسخة احتياطية أو ضمان استعادة من فقد القرص. عند استعادة نسخة لاحقة يلزم التطهير قبل إتاحة التطبيق. لا نسخ احتياطية حقيقية أنشئت أو استعيدت هنا.

## الصيانة والتراجع

خدمة `retention` تعمل كل ساعة، بعد مدة الاحتفاظ المعتمدة: سبعة أيام بعد انتهاء الجلسة الفعلي. API بحساب غير superuser وبلا صلاحية استدعاء الحذف. الأداة `tools/purge-guests.mjs` تعمل dry-run افتراضيًا؛ `--apply` يتطلب اتصال صيانة مستقلًا في `RETENTION_DATABASE_URL`. لا تشغّلها على بيانات حقيقية دون إذن مستقل.

ترحيل `0010_guest_retention` إضافي، لا يغير API/JSON. التراجع المحلي `qa/retention-down.sql` يزيل الدالة ويعيد حماية التاريخ الأصلية؛ اختبر داخل معاملة مع rollback. التراجع لا يعيد الصفوف المحذوفة ولا يطبق آليًا على قاعدة حقيقية.

## سيناريو عرض تعليمي

1. ابدأ ضيفًا دون معلومات هوية. وضح Desktop MVP ووسم البنك الاصطناعي ومراجعته التعليمية المعلقة.
2. اختر `٢(س + ٣) = ١٠`، وأدخل `٢س + ٣ = ١٠`: حكم SymPy غير مكافئ وفرضية توزيع حذرة.
3. افتح السؤال؛ «لا أدري» يبقي السبب غير محسوم. تدرج H1…H3؛ H4 بتأكيد مستقل مع سجل مساعدة، لا إنجاز مستقل.
4. افتح العلاج. أدخل خطوة خاطئة واطلب تلميحًا مراجعًا عند توفره، ثم صحح وتحقق. افتح نقلًا مختلفًا وحله دون مساعدة. طلب مساعدة النقل يخرج من القياس ويسحب أهلية الاستقلال.
5. أدخل انتقالًا مكافئًا جديدًا مثل `س + ٤ = ٦` للمسألة الأصلية، ثم `جا(س) = ١` لإثبات الامتناع الآمن.
6. افتح `/demo/teacher` واشرح وسم المصدر والعينة الاصطناعية؛ لا تعرضه كبيانات ضيوف أو تحسن فعلي.
