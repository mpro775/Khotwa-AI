# 19 — سجل القرارات المطلوبة وحدود التفويض

## قرارات مصرح بها بهذه الحزمة

1. تطوير **A1 إلى A8 جميعها** على السورس الحالي (بعد تدقيق HEAD) مع إعادة استخدام NestJS/Prisma/PostgreSQL/React/Math Gateway.
2. صياغة سياسة حتمية قابلة للتفسير أولًا بدل بناء Knowledge Tracing machine learning قبل توفر بيانات كافية.
3. التمييز الصارم بين المساعدة والاستقلال والنقل والاحتفاظ؛ عدم تقديم «درجة إتقان احتمالية» غير معايرة.
4. تطوير أسئلة تشخيص مراجع ومحادثة سقراطية offline، وعرض مراجعات وتطبيقات صغيرة داخل النطاق العلمي المعتمد.
5. التغيير محلي على فرع تطوير، مع العقود/الاختبارات/reporting، والتكامل مع V2.2 دون استبدال بنيته.

## قرارات لا تستنتج من هذا التفويض

| ID | الموضوع | الحالة الحالية | ماذا يفعل الوكيل؟ |
|---|---|---|---|
| `A-DEC-01` | نشر للمستخدمين الحقيقيين | غير مصرح | يترك feature flags مغلقة ويتحقق ببيانات اصطناعية |
| `A-DEC-02` | موافقة المحتوى العلمي لـA3/A4/A6/A7 | لا توجد موافقة جديدة تلقائية | يعد نسخًا قابلة للمراجعة؛ لا ينسب موافقة لمختص دون دليل |
| `A-DEC-03` | تعديل Golden أو حسم `GOLD-DIAG-015` | معلق في V2.2 | يحافظ على المرجع ويبلغ المراجع؛ لا يغير expected results |
| `A-DEC-04` | ارتباط `ERR-ALG-05` مع مهارة SK06 | معلق | يستخدم mapping الحالي فقط في حدود القرار، ولا يقلبه من تلقاء نفسه |
| `A-DEC-05` | عتبات الإتقان/فترات المراجعة النهائية | تحتاج معايرة | يطبق قواعد **تجريبية versioned** في synthetic، لا يتعامل معها كحقائق علمية أو سياسة نشر |
| `A-DEC-06` | محتوى الفيزياء الشامل | يحتاج مختص | يبقي نطاقًا محدودًا، لا يفعّل خمس هياكل غير مكتملة |
| `A-DEC-07` | تشغيل Python code-runner في مسارات الطلاب | غير مفوض | reading-only أو evaluator محدد غير تنفيذي مراجع |
| `A-DEC-08` | مزود LLM خارجي وميزانية/خصوصية | غير مصرح | offline reviewed templates فقط؛ الاتصال الخارجي OFF |
| `A-DEC-09` | retention/deletion policy جديدة | لا تفويض | الالتزام بالسياسة القائمة وتوثيق ثغرات الدمج دون تغيير المدة |
| `A-DEC-10` | إطلاق B1/B2/B3/C1…C7 أو V2.3 | خارج النطاق | توقف عند A8 |

## كيفية تسجيل خلاف أو فجوة

سجّل سجلًا في `qa-reports/A-SPEC-CONFLICTS.md`:

```text
SPEC-CONFLICT-ID:
المكوّن/المرحلة:
الملف المالك/السطر أو commit:
ماذا تقول المواصفة الجديدة؟
ماذا يقول المصدر القديم أو العقد؟
الأثر على البيانات/المحتوى/الأمن/القياس:
البدائل الممكنة:
الجزء المتوقف فقط:
صاحب القرار المناسب:
الحالة: OPEN | RESOLVED | DEFERRED
```

لا يلزم وقف البرنامج كله بسبب مراجعة محتوى غير مرتبطة بعمل backend آمن. وفي المقابل، عدم وجود موافقة علمية على الـprobe لا يبرر تعميمه على الطلاب أو وصفه بأنه موثوق.
