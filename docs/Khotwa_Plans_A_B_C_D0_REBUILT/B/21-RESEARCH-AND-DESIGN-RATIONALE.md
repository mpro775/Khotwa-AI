# 21 — الأساس العلمي والمفاهيم التربوية للمختبرات

**الفصل بين الأدلة والتصميم:** المراجع أدناه تدعم مبادئ تربوية عامة، لكن لا تثبت أن تنفيذ خُطوة الخاص سيكون فعالًا بمجرد نجاح الاختبارات البرمجية؛ نحتاج بعد البناء دراسات قبلية/بعدية وتأخرية مع متعلمين حقيقيين وموافقات مناسبة.

## B1 — رياضيات

- **الأمثلة المحلولة والمتدرّجة:** استخدم نموذجًا صحيحًا ثم أمثلة جزئية ثم مسائل مستقلة؛ أزِل الدعم بالتدريج ولا تجعل كل النشاط خطوة محفوظة.
- **المزج بين الرسوم والشرح اللفظي:** جدول + رسم + معادلة يخدم الفهم حين يعكس المبدأ نفسه بوضوح؛ لا تجمع 3 تمثيلات متناقضة.
- **الأسئلة التفسيرية:** اسأل «لماذا يصح التحويل؟» و«أين أول خطأ؟» مع content reviewed، ولا تحول إجابة إنشائية واحدة إلى إتقان.
- **المقارنة بين الاستراتيجيات:** طريقة بديلة صحيحة ليست خطأ لأنها لا تشبه نموذج المعلّم؛ validator هو مرجع معنى التكافؤ ضمن النطاق.

## B2 — فيزياء

- **التعلم الاستقصائي الموجه:** اختيار متغيرات مضبوطة ثم توقع نتيجة واختبارها وتفسيرها. المحاكاة دون سؤال أو تفسير ليست هدفًا تربويًا كاملًا.
- **أهمية الافتراضات:** نموذج سرعة ثابتة لا يماثل نموذج احتكاك أو حركة ثنائية الأبعاد؛ سوء ضبط النموذج يعلّم قانونًا خاطئًا مهما كانت الواجهة جذابة.
- **النقل:** بعد مشاهدة التجربة يُقيّم الطالب بموقف جديد وبنك غير متعرض، لا بنفس قيم المنزلق.

## B3 — برمجة

- **تتبع التنفيذ:** يجعل الطالب يربط كل سطر بتغير حالة البرنامج قبل كتابة كود من الصفر.
- **Parsons:** يقلل عبء كتابة syntax في البداية ويُركز على ترتيب المنطق، مع السماح بأكثر من حل مرتب صالح عند الاقتضاء.
- **التصحيح:** يواجه الطالب code غير صحيح ويقترح إصلاحًا، ويتحرك تدريجيًا إلى كتابة كود فعلي فقط ضمن Runner معزول.

## إشارات تقييم لاحقة (خارج تفويض تطوير هذه الحزمة)

- B1: نسبة تحديد أول خطأ صحيح في مسائل جديدة، تفسير مبدأ التحويل، نجاح مؤجل بعد أسبوعين، وتراجع طلب H2/H3.
- B2: جودة توقع المتغير المسيطر، تفسير الفرق مسافة/إزاحة، نجاح القيمة/الوحدة في سياق جديد، الاحتفاظ بعد مدة.
- B3: دقة trace على أمثلة جديدة، انتقال الطالب من Parsons إلى كتابة كود مستقل، انخفاض أخطاء off-by-one، نجاح hidden tests بدون مساعدة.
- **لا تستخدم** عدد النقرات أو زمن الجلسة أو التفاعل مع منزلق وحده بوصفه تحسنًا علميًا.
