## 2. أول نطاق تعليمي إلزامي

ابدأ بحركة خطية أحادية البعد `kinematics_1d`؛ وهي المجال الذي تدعمه بنية التحقق الحالي في `physics.py`. أنشطة مقترحة:

- **سرعة ثابتة:** تغيير `v` و`t` وملاحظة `d = |v|t` للمسافة في حركة دون انعكاسات، أو `Δx = vt` للإزاحة. اشرح الفرق وقيد الافتراضات.
- **تسارع منتظم:** `v = v0 + at`, `Δx = v0 t + 1/2 a t²` ضمن النطاق الذي تسمح به الصيغ الأصلية؛ إن كان نموذج Python الحالي لا يغطي حالة مهمة، اكتب مواصفة توسعة منفصلة ومراجعة قبل اعتبارها مدعومة.
- **قيمة/وحدة:** `m`, `s`, `m/s`, `m/s²`, `km/h` ضمن whitelist الأصلية، مع تحويلات صحيحة وعرض SI.

**لا تطلق في هذه المرحلة رسم قوى سطح مائل أو احتكاك أو مقذوفات ثنائية الأبعاد كأنها متحققة من الفيزياء الحالية.** يمكن اقتراحها لاحقًا فقط تحت modelVersion مختلف مع oracle واختبارات وخبير.

## 3. سلوك رحلة التنبؤ

1. يظهر الموقف والمتغير الذي سيغيره الطالب، و**لا تُعرض النتيجة التجريبية محل السؤال مسبقًا**.
2. يقدّم توقعًا قابلًا للتحقق: اتجاه التغير (يزيد/يقل/يبقى) أو مجال عددي ومبرره؛ يخزن snapshot قبل reveal.
3. ينقر «ابدأ التجربة» فتُولّد النتائج من نموذج deterministic reviewed، والبيانات الوصفية graph/time series تُعتمد خادميًا أو تُتحقق وفق contract.
4. يلاحظ ثم يكتب/يختار تفسيرًا، ويقارن مع توقعه: «توقعي لم يطابق النتيجة؛ لماذا؟» لا يُصنّف خطأ الاعتقاد فورًا كعيب دائم.
5. إذا أراد تلميحًا يسجل المساعدة؛ يمكن عرض توضيح رسم أو قانون.
6. قياس الاستقلال من `assessments`/A2 **بسؤال جديد** مستقل مع قيمة/وحدة؛ لا يُعاد استخدام نفس المحاكاة المكشوفة بوصفها قياسًا.

## 4. محتوى تربوي مطلوب

- لكل تجربة: `phenomenon`, `learningObjective`, `scientificAssumptions`, `controlledVariables`, `independent/dependentVariable`, `validRanges`, `predictionPrompt`, `observationPrompt`, `explanationRubric`, `reviewedReference`, `transferFamily`.
- خطأ `wrong_value` أو `wrong_unit` يشير لنتيجة حساب/وحدة؛ لا يعني مفهوماً خاطئًا مؤكدًا، ويُحال إلى A3 probe عند توفر قالب مراجع.
- يُطلب تغيير **متغير واحد** أولًا ثم مقارنة تغيير متغيرين لاحقًا؛ تظهر «ما الذي ثبتناه؟» لتعليم ضبط المتغيرات.
- لا يصدر LLM حكمًا علميًا أو يحقن قوانين غير متحققة.
