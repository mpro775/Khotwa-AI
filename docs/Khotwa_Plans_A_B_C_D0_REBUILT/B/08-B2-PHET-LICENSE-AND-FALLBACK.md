## إن تقرر التكامل لاحقًا بعد الترخيص

1. اعمل على URL allowlist صريح من `https://phet.colorado.edu`، لا URL يأتي من المستخدم أو Studio بلا تحقق، مع `frame-src` CSP مناسب حسب الاتفاقية.
2. اعرض وسم المصدر ونص الإسناد الإلزامي قرب المحاكاة ولا تخفِ شعار PhET.
3. لا تُصدر بيانات شخصية للطالب عبر querystring أو analytics؛ راجع سياسة الطرف الثالث/خصوصيته وبند موافقة المستخدم.
4. لا تعتبر نشاط PhET الخارجي قياسًا مستقلًا بسبب عدم التحكم الموثوق بالأحداث؛ لإشراكه بالتقييم استخدم سؤالًا **جديدًا** متحققًا من مصدر خُطوة.
5. إذا تعذر iframe (محتوى محظور، عطل، خصوصية، شبكة، ترخيص)، اعرض بديل المختبر الأصلي دون خسارة التقدم.

## قبول B2 بدون PhET

يعد B2 **مكتملًا تقنيًا ضمن نطاقه** إذا نجحت محاكيات خُطوة الأصلية والأنشطة والقياس والاختبارات، حتى لو ظل تكامل PhET `BLOCKED_LICENSE`. لا تجعل شراء ترخيص شرطًا لإكمال المشروع البرمجي، ولا تتجاوز القانون لتجاوز البوابة.
