# 24 — سيناريو القبول اليدوي للمختبرات (بعد code QA)

هذه خطوات **اختبار يدوي محلي بأسماء وبيانات اصطناعية فقط**. لا تجرّب على حسابات طلاب حقيقيين دون تفويض وموافقة مناسبة. لا تشغّل Runner إذا كان Gate-R مغلقًا.

## 1. B1 — الرياضيات

1. افتح مسار جبر **منشور داخل مختبر اختبار** ودرس توزيع الأقواس ذي block B1 معتمد للمختبر.
2. شاهد المثال ثم اجعل المعامل يتغير، وراقب توافق الجدول والرسم/المعادلة. جرّب قيمًا موجبة وسالبة وصفرية.
3. افتح نشاط «أول خطوة خاطئة» واختر انتقالًا غير صحيح. تحقق من تفسيره دون عرض الحل الكامل قبل الطلب.
4. قارن طريقتين صحيحيتين، وراجع أن مسارًا بديلًا لا يُرفض لأنه مختلف عن النص.
5. اكشف مثالًا أو تلميحًا، ثم ابدأ طلب تقييم مستقل. تحقق أن نفس السؤال/العائلة المكشوفة لا تستخدم كدليل مستقل.
6. أغلق/أعد فتح الصفحة. تأكد من استئناف الحالة في النسخة المنشورة الموثقة، حتى لو نشر المُعلم نسخة لاحقة.

## 2. B2 — الفيزياء

1. افتح تجربة «حركة بسرعة ثابتة»: تحقق أن النتائج غير معروضة في مرحلة التوقع.
2. اختر توقعًا أو «لا أعرف»؛ ابدأ تجربة `3m/s` لمدة `4s`، ثم ضاعف الزمن. تتبع 12m ثم24m، واستخدم جدول البيانات عند إغلاق الرسم.
3. غيّر السرعة إلى `-3m/s`: تحقق من ظهور إزاحة -12m ومسافة +12m.
4. جرّب مدلول وحدة خاطئة في سؤال القيمة/الوحدة. تأكد أنه لا يعلن سبب سوء فهم قاطعًا.
5. إذا أظهر البرنامج حالة انعكاس اتجاه، تحقق من معاملتها وفق نموذج معتمد، لا الصيغة المختزلة الخاطئة.
6. عند PhET flag off أو عدم وجود ترخيص، تأكد من أن التجربة المحلية كاملة ولا iframe أو تحميل أصول خارجية.

## 3. B3 — البرمجة

1. افتح درس Python؛ توقع الناتج للبرنامج الذي يجمع 1 إلى 3 قبل إظهار trace.
2. نفذ trace خطوة خطوة يدويًا؛ الناتج 6، وتظهر قيم المجموع 1,3,6 بوضوح.
3. نفذ Parsons عبر لوحة المفاتيح فقط، وتحقق من indentation والرسائل العربية.
4. حل تمرين debugging عن `range(1,3)`؛ شاهد لماذا لا يشمل 3 وعالج بالمراجعة المعتمدة.
5. عندما `RUNNER` معطل، تأكد من أن نشاط Python static يعمل وأن التشغيل لا يُسمح به عبر واجهة أو API.
6. **فقط بعد بوابة أمنية منفصلة** اختبر `run` و`submit` في sandbox مخصص، واختبر فشل خدمة runner دون ضياع code.

## 4. مشاهدات جودة مشتركة

- شاشة هاتف، شاشة حاسوب، تكبير 200%، تنقل Tab/Enter، قارئ الشاشة عند توفره، reduced-motion، بطء شبكة واختفاء مؤقت.
- نسخة درس draft/archived لا تظهر لطالب جديد؛ طالب سابق لا يرى نسخة طالب آخر.
- زر «لا أعرف» موجود في التوقعات دون عقاب، وحالة unverified تعرض رسالة حيادية.
- كل تجربة تعرض بوضوح «تدريب» أو «تقييم مستقل»؛ لا يمنح أي رسم أو drag badge إتقان.
- إذا لم يوجد سؤال مستقل جديد يقول «لا يوجد بنك كافٍ» بدل إظهار درجة نجاح وهمية.
