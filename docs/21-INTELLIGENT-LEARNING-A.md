# Intelligent Learning A — سجل التنفيذ

2026-11-08، امتداد محلي اصطناعي فوق V2.2. الطلب المصدر من المالك: «نفذ هذا المطلوب كاملا» مع ملفات الحزمة `KHOTWA-A-INTELLIGENT-LEARNING/00…20`. يشمل التنفيذ A1–A8 والعقود واختبار المصدر، ولا يمنح اعتماد محتوى أو نشرًا أو إذن تعلم حقيقي أو AI خارجي أو Runner. المرجع السلوكي هو الحزمة؛ العقد العام إصدار `1.4.0-development`.

## توزيع المسؤوليات

React → NestJS → Prisma/PostgreSQL ومحرك المجال القائم. القرارات والإسقاطات لا تحكم صحة الإجابات. حقائق الصحة من verification_reports/subject_attempts الحالية فقط. التقييمات المستقلة والاسترجاعية تستخدم orchestrator الحالي مع novelty والملكية والإصدارات؛ لا جدول إتقان علمي جديد.

`intelligent_learning_records` مخزن حالة مملوك محدود الأنواع (قرار/نشاط/مراجعة/دعم/حوار/هدف/تأمل)، مع مراجعة ذرية ونسخ تاريخية في `intelligent_learning_events`. جداول إضافية لا تستبدل الأدلة أو المحتوى. ترحيل 0023 يضيف القيود والفهارس ويوسع نوع التقييم. روابط القرار والنشاط مملوكة، وقبول القرار لا يتكرر. نقل الضيف للحساب ينقل الحالة والأحداث مع claim الأصلي؛ purge يحذفها في ترتيب آمن وفق المدة القديمة دون سياسة احتفاظ جديدة.

## التفعيل

كل مفتاح من `PEDAGOGY_ENGINE_ENABLED`, `MASTERY_PROJECTION_ENABLED`, `DEEP_DIAGNOSIS_ENABLED`, `KNOWLEDGE_GRAPH_A_ENABLED`, `SPACED_REVIEW_ENABLED`, `FADING_SCAFFOLD_ENABLED`, `SOCRATIC_TUTOR_ENABLED`, `METACOGNITION_ENABLED` مغلق افتراضيًا. علاوة على ذلك، العمليات الجديدة محجوبة خادميًا خارج بيانات البيئة الاصطناعية. `SOCRATIC_EXTERNAL_AI_ENABLED` موثق مغلق، ولا يركب هذا البرنامج مزودًا خارجيًا. إغلاق flags يعيد واجهة V2.2 دون حذف التاريخ.

إعدادات الإتقان والمواعيد وسقف الحوار تجريبية ذات نسخ، ليست عتبات قبول علمية معتمدة. المحتوى المنشور في اختبار اصطناعي لا يحمل توقيع مختص. GOLD-DIAG-015 وERR-ALG-05/SK06 لا يزالان معلقين. Python قراءة فقط دون شهادة أداء تنفيذي. لا إعادة تصنيف نتيجة فنية كضعف مفاهيمي أو تقرير ذاتي كإتقان.

تستعمل تقييمات V2.2 نوع المحاولة `transfer` تاريخيًا. يعرض A3 فرضية محافظة من حكم حالي وAST محللة بمحرك المادة، ولا يفتح probe أثناء القياس. الطلب الصريح يسجل خروج عنصر التقييم أولًا ثم يعيد خدمة التحقق الأصلية ويستعمل خدمة التشخيص/probe القائمة؛ الاستثناء محصور بمسألة مسار اصطناعية خرجت من القياس مع العلم A3، ولا يشمل إسناد نقل أصليًا أو مساعدة H1–H4 سابقة. لا تتغير تسمية المحاولة أو أحكامها القديمة، ولا تعد إجابة السؤال التأكيدي أداءً مستقلًا للمسألة الأصلية.

## المراجعة والأدلة

النتيجة الحالية في [التقرير الموحد](../qa-reports/A-INTELLIGENT-LEARNING-FINAL-ACCEPTANCE.md): 66 اختبار مصدر/وحدة و17 انحدارًا سابقًا و14 اختبار تكامل ناجحة، مع 238 استجابة HTTP موثقة. القبول النهائي PARTIAL للمحتوى والفحص المرئي؛ شهادة HTTPS المحلية منعت الوصول إلى Chrome، دون تجاوز التحذير. بصمة المصدر وGolden في [manifest المراجعة](../qa-reports/A-RELEASE-CANDIDATE.json).

أوامر إعادة الفحص من جذر المستودع:

```text
npm run test:intelligent
npm run test:intelligent:integration
node tools/check-intelligent-learning.mjs
```

الأمر الثاني ينشئ PostgreSQL ومحرك رياضيات مؤقتين بأسماء عشوائية ومنفذ loopback، ويطبق الترحيلات على قاعدة الاختبار الجديدة فقط، ثم يزيل موارده الخاصة. يحتاج Docker والصورة المحلية لمحرك الرياضيات؛ لا يستعمل قاعدة العرض أو أي بيانات حقيقية. الاختبارات لا تنادي AI أو Runner.

البداية والفجوات في `qa-reports/A-BASELINE.md` و`A-SPEC-CONFLICTS.md`. تقارير A1…A8 والتقرير التجميعي يسجلون الاختبارات الفعلية وحدودها. لا ترحيل لقاعدة مستخدمين قائمة أو إنتاج، ولا push/merge/deploy. تجربة قاعدة مؤقتة مملوكة للاختبار، إن شُغّلت، تسجل مستقلة عن مراجعة الأجهزة والمحتوى والقبول الإنتاجي.
