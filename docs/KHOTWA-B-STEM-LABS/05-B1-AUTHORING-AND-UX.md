# 05 — B1 | استوديو تأليف الرياضيات وتجربة الطالب

## 1. امتداد `LessonBlock` الآمن

يُستحسن إضافة أنواع **محددة** لا «JSON عام أو JSX من المعلم»:

- `math_graph_activity`: model `linear_function_v1` ومجال معاملات/عرض وهدف تربوي و`skillCodes`.
- `math_method_comparison`: `methodA`, `methodB`, `reviewedRubricId`, ونسخ الحلول المثبتة.
- `math_first_error`: سلسلة انتقالات فيها خطأ مقصود، مع علامة author-only وvalidator mode.
- `math_why_question`: سؤال مبررات وخيارات مراجعة وحقل تفسير اختياري.
- `math_completion`: `A6` step-fill نشاط مساعد مع answer checks.

إذا أضاف A6 نوع `completion_step` مسبقًا، استخدمه **ولا تخلق نوعًا مكررًا**. عند تعديل `learning-path-payload.ts` تحدّث حدود الحجم، نوع المواد المسموح، وحفظ snapshots، والعقود المولّدة.

## 2. واجهة الطالب

- بطاقة تمهيدية «هدف هذه التجربة» و«كيف أستخدمها»، ومفتاح «عرض البيانات كجدول» مقابل الرسم.
- أداة محاور ذات تسميات عربية، أمثلة أعداد سالبة، تدرج قيم واضح، دعم قارئ الشاشة، مؤشر active state لا يعتمد على اللون وحده.
- عند تعديل المعاملات تُعرض النتيجة فورًا باعتبارها **تجربة استكشافية**؛ بعد ذلك سؤال «ماذا تغير ولماذا؟» في نشاط منفصل.
- compare يعرض طريقتين جنبًا إلى جنب على الحاسوب ومتتاليتين على الهاتف، مع toggles لإظهار سبب كل انتقال وخاصية نسخ نصية.
- أول خطأ يطلب اختيار transition؛ لا يكشف الحل الكامل قبل تسجيل المساعدة عند الطلب، ويتجنب تبخيس الطالب بعبارات «أنت لا تفهم».
- `unsupported` لا يعطل الصفحة؛ يظهر سبب حدود الأداة وخيار الرجوع للمثال النصي.

## 3. واجهة المؤلف/المراجع

- نموذج منظّم للمجال والمعاملات والمرحلة، preview لكل block عبر `LessonRenderer` مع بيانات اصطناعية، لا fetch من حساب طالب.
- زر «تحقق من صحة أمثلة المعادلات» يشغّل math validator في الخادم ويعيد statuses مفصلة؛ لا يسمح بالنشر إذا أخطأت دعوى «حل صحيح».
- وضع `common_mistake` يطلب تمييزه صراحة كخطأ تعليمي مقصود، مع سبب وتحذير مرئي، ومراجعة مدرس.
- لكل نشاط: objective, targetSkill, priorPrerequisites, expectedMisconceptions, helpPolicy, reviewStatus, reviewActor, verifiedAt, engineVersion.
- اختيار نطاق الاختبار المستقل منفصل عن أنشطة الرسم، مع familyCode/novelty gate للحفاظ على القياس.

## 4. محتوى البداية المقترح (غير معتمد بعد)

- `ALG-L04`: التوزيع؛ نشاط مقارنة وتحليل الخطأ الأول.
- `ALG-L02`: موازنة طرفي المعادلة؛ تمثيل المتساويين ورسم خطين للنقطة المتحققة.
- `ALG-L05`: المعامل السالب؛ مقارنة طرق المعالجة وحفظ الإشارات.
- لا تستكمل جميع 18 درسًا في B1 من دون مراجعة منفصلة؛ أنشئ عددًا محدودًا من الأنشطة *كعينات قابلة للترقية*.

## 5. قبول واجهة المنتج

- RTL عربي وdir=ltr لمعادلات raw وفق سياسة المحرر، والتصحيح يقرأه قارئ الشاشة.
- لا تعرض graph إذا لا توجد بيانات صالحة؛ fallback جدول/نص، ولا يختفي إدخال الطالب.
- لا يسجل اختيار/drag/slider **إتقانًا** حتى عند الوصول لموقع الرسم الصحيح؛ يُسجّل learning interaction اختياريًا بحدود privacy.
- درس archived المثبت لطالب سابق يعمل بعد نشر revision جديد دون إعادة كتابة التاريخ.
