# تشغيل V2.2 للاختبار اليدوي على Windows

هذه بيئة **اختبار محلية اصطناعية محفوظة**، ولا تفعّل Beta أو البريد أو AI الخارجي أو Runner. قاعدة `v22_manual` وحاوياتها منفصلة عن قواعد المستخدم والبيئات السابقة. لا يساوي اعتماد الحساب الاختباري داخل الاستوديو مراجعة الأستاذ مراد سيف للمحتوى.

## المتطلبات والتشغيل

يلزم PowerShell7 وOpenSSL (المرفق مع Git for Windows أو المتاح على PATH)، وNode/npm وتبعيات المستودع المثبتة وDocker Desktop، والصورتان المحليتان `postgres:17.6-alpine3.22` و`khotwa-mvp-local-math:latest`. شغّل الأوامر من جذر المشروع. إذا كانت البيئة تعمل بالفعل، افتح الروابط مباشرة ولا تشغّل نسخة ثانية على المنفذ نفسه:

```powershell
npm run build
pwsh -NoProfile -File tools/v22-local-https.ps1 -Action Prepare
pwsh -NoProfile -File tools/v22-local-https.ps1 -Action Trust
node tools/serve-v22.mjs
```

أمر شهادة التطوير ينشئ شهادة localhost محددة ويثق بها للمستخدم الحالي. لا تغيّر إعدادات تحذيرات Chrome، ولا تستخدم `--ignore-certificate-errors` أو تعطيل فحص TLS. تفاصيل الشهادة وأثر الثقة موثقة في `qa-reports/V2.2-HTTPS-SETUP.json`؛ شهادة ومفتاح الخادم محليان داخل `.local/v22-tls/` ولا يرفعان إلى Git.

لفحص الشهادة والثقة لاحقًا، أو إزالة **ثقة هذه الشهادة المُدارة فقط** بعد انتهاء الاختبار:

```powershell
pwsh -NoProfile -File tools/v22-local-https.ps1 -Action Status
# عند إنهاء استعمال بيئة الاختبار؛ لا ينفذ ضمن رحلة القبول الجارية:
pwsh -NoProfile -File tools/v22-local-https.ps1 -Action RemoveTrust
```

إزالة الثقة لا تحذف المحاولات أو قاعدة الاختبار؛ ستتطلب زيارة HTTPS تهيئة الثقة الصحيحة مجددًا. لا يغير أي من الأوامر شهادة موقع عام أو إعدادات حماية Chrome.

افتح في Chrome:

- الطالب أ: **https://localhost:8462/__v22/student-a**
- المعلم الاختباري المخول للمراجعة والنشر: **https://localhost:8462/__v22/teacher**
- الطالب ب لفحص عزل الملكية: **https://localhost:8462/__v22/student-b**
- الطالب ج لرحلة جديدة دون التعرضات السابقة: **https://localhost:8462/__v22/student-c**

روابط اختيار الهوية جزء من أداة الاختبار المحلية فقط، ولا تضيف bypass إلى Controllers تطبيق الإنتاج. المعلم الاختباري يحمل دور `admin` داخل قاعدة الاختبار حتى يمكن تجربة دورة النشر القائمة. الشريط الأصفر يعلن بوضوح أن هذه موافقات تقنية اصطناعية.

تتشارك التبويبات في **Chrome profile نفسه** ملف ارتباط الحساب؛ لا تعني نافذة طالب ومعلم بهويتين متزامنتين داخل profile واحد. بدّل الدور من روابط الشريط الأصفر، أو استخدم Chrome profile منفصلًا للعرض المتزامن. إذا أعاد انتقال خارجي إلى helper كود403، افتح `https://localhost:8462/` أولًا ثم اضغط رابط الدور من الشريط نفسه؛ لا تخفف شرط same-origin ولا حماية المتصفح.

## تشغيل مخفي يبقى بعد إغلاق نافذة الطرفية

بعد نجاح إعداد الشهادة والبناء، يمكن تشغيل السيرفر في الخلفية دون نافذة جديدة:

```powershell
$v22Node = (Get-Command node).Source
$v22Root = (Get-Location).Path
$v22Out = Join-Path $v22Root '.local/v22-manual/server.stdout.log'
$v22Err = Join-Path $v22Root '.local/v22-manual/server.stderr.log'
New-Item -ItemType Directory -Force -Path '.local/v22-manual' | Out-Null
Start-Process -FilePath $v22Node -ArgumentList 'tools/serve-v22.mjs' -WorkingDirectory $v22Root -WindowStyle Hidden -RedirectStandardOutput $v22Out -RedirectStandardError $v22Err
```

انتظر ظهور `V2.2 manual test environment ready` في سجل stdout ثم افتح الروابط. المنفذ8462 ثابت ومقصور على loopback. مسار `runtime.json` في `.local/v22-manual/` يحوي PID وروابط البيئة وأسماء الموارد ومعرفات المحتوى، ولا يحوي أسرار الجلسات.

تُعرض ملفات React **المبنية فعليًا** من `apps/web/dist` عبر HTTPS، وتذهب `/api/v1/` إلى NestJS الخاص على loopback. لا يعيد الخادم واجهة Mock أو نتائج تحقق مخزنة. عند تعديل ملفات الواجهة لاحقًا، أعد بناء الحزمة ثم أعد تحميل الصفحة.

## الحفظ والإيقاف وإعادة التشغيل

```powershell
node tools/serve-v22.mjs --status
node tools/serve-v22.mjs --stop
```

الإيقاف يغلق الواجهة وNestJS ويوقف حاويتي الاختبار المملوكتين للأداة. انتظر رسالة `Stopped; database volume, content versions and attempts retained` قبل إعادة التشغيل. **لا يحذف حاويات أو volume أو بيانات أو مراجعات أو محاولات**. التشغيل التالي بالأمر نفسه يعيد استعمال PostgreSQL named volume ومعرفات الحسابات والمحتوى. الـseed ذو علامة محفوظة؛ لا يعيد إنشاء الدروس ولا يكتب فوق ما عدّله المختبر ولا ينشر revision جديدة تلقائيًا عند إعادة التشغيل.

لا تحذف `.local/v22-manual/private-config.json`: يحوي إعدادات البيئة المحلية والأسرار العشوائية المحمية بـACL للمستخدم الحالي وSYSTEM. يبقى داخل `.gitignore`. كما لا تحذف Docker volume المسمى في `runtime.json` إذا أردت الاحتفاظ بمحاولات الاختبار.

البيئة تهيئ28 مسألة جبر اصطناعية متحققًا منها حسابيًا (24 main و4 transfer) و6 مسائل فيزياء، وتترك درس الجبر ومساره **draft** ليجرب المراجع تأليف نسخة ونشرها عبر الواجهة. مسارا الفيزياء وPython المنشوران هنا fixtures تقنية موسومة فقط؛ حزمة الدروس الجديدة الأصلية تبقى غير معتمدة تربويًا.

## أدلة المصدر الحقيقي

```powershell
node tools/serve-v22.mjs --evidence
```

ينشئ `qa-reports/V2.2-MANUAL-RUNTIME-EVIDENCE.json` من PostgreSQL الفعلي: نسخ المحتوى وحالاتها، ومعرفات التقييم، وإصدارات المحاولات، وأحكام التقارير وإصدار محرك الجبر، وحالات محاولات المواد. لا يصدّر إجابات الطالب الخام أو مفاتيح الحل أو cookies أو tokens أو كلمات المرور.

سجل `.local/v22-manual/requests.ndjson` يربط أفعال المتصفح بطلبات NestJS: وقت وطريقة ومسار الطلب وكود HTTP و`X-Request-Id` فقط. لا أجسام طلبات أو رؤوس مصادقة. دليل الأسئلة العلني في `.local/v22-manual/bank-index.json` يذكر المعرفات والمعادلات والعناوين دون الإجابات.

## إعادة تجربة المسارات مع الحفاظ على المحاولات

ابدأ من بطاقات المواد في «الدروس» ثم المسار المنشور. لا تفتح «بنك المسائل ومساحات التدريب الحالية» ولا تضغط تحديث بنك المسائل قبل القياس المستقل: فتح البنك يعرض أسئلته ويسجل تعرضًا صحيحًا، وقد لا تبقى أسئلة جديدة كافية للقياس. صار تحميل هذا البنك عند طلبه صراحة فقط؛ لا يُحمّل تلقائيًا عند دخول المسارات.

للجبر: افتح الدرس المنشور ← اختبر مستواك ← جرّب تحويلًا غير مكافئ ← الملخص والتوصية ← الدرس والتدريب بتلميح ← سؤال جديد بعد التدريب. بعد النجاح يمكن استئناف المحاولة نفسها؛ لا تمحُ سجل التعرضات للحصول على نتيجة مستقلة ثانية من السؤال نفسه.

للفيزياء: استخدم الطالب ج عند الحاجة إلى سجل جديد، ثم «الفيزياء ← الحركة الخطية والوحدات ← السرعة والمسافة والوحدات»؛ ابدأ التدريب وأدخل قيمة ووحدة، ثم «سؤال جديد بعد التدريب» لسؤالين مختلفين. لبرمجة Python افتح المسار والدرس في وضع القراءة فقط. بقاء زر التقييم محجوبًا قبل اعتماد Runner مقصود.

إذا نفد البنك الجديد لهوية ما، احتفظ بمحاولاتها واستخدم هوية اختبار أخرى أو أضف أسئلة جديدة مختلفة عبر المعلم الاختباري؛ لا تحذف إصدارات المحتوى أو المحاولات أو التعرضات لتجاوز شرط الاستقلال.

للخطوات ونتائج Chrome الفعلية وحالة القبول، راجع `qa-reports/V2.2-FINAL-ACCEPTANCE.md`. لا تبدأ V2.3 ولا تنشر هذه البيئة للعامة.
