# أمر التنفيذ الجاهز للوكيل — KHOTWA V2.2

**التكليف:** نفّذ **V2.2 Learning Paths & Adaptive Remediation** كاملة وفق الملفات المرفقة بهذه الحزمة، دون الانتقال إلى الإصدارات التالية.

## اقرأ أولًا
`00-START-HERE.md` ثم `01` إلى `07` بالترتيب، وراجع `AGENTS.md` والنسخة الأحدث من المصدر والتدقيق `DEV-CODE-COMPLETENESS-AUDIT.md`.

## نفّذ بالتسلسل
1. **TASK-LP-01:** هيكل مواد/مسارات/دروس وإصداراتها ودرس عربي فعلي. أعد استخدام جداول المحتوى والمهارات الحالية.
2. **TASK-LP-02:** خريطة المهارات والأخطاء والمقدمات ↔ الدروس مع ثقة تشخيص متحفظة وقضايا المنهج المفتوحة.
3. **TASK-LP-03:** تقييم قصير مستقل، وتحليل أدلة، ومحرك توصية بسيط، وعلاج وسؤال نقل مستقل.
4. **TASK-LP-04:** وصل شاشات الطالب «تعلم» و«اختبر مستواك» ودرس/تقييم/توصية/تقدم بالـAPI الحقيقي، دون mocks للرحلة النهائية.
5. **TASK-LP-05:** وصل استوديو المعلم لتأليف ومراجعة ونشر الدروس والمسارات وربط الأسئلة.
6. **TASK-LP-06:** طبّق بنية المسارات نفسها على الفيزياء وPython ضمن المحتوى والخدمات الموجودة، مع إبقاء ما لم يعتمد أو لم يجهز آمنًا ومحجوبًا.
7. **TASK-LP-07:** lint/typecheck/build/contracts، واختبارات الوحدات المتأثرة، ورحلة تكامل محلية كاملة للجبر ببيانات اصطناعية وقاعدة اختبار، ثم التقرير.

## مبادئ تنفيذ
- لا تعِد إنشاء النظام: استخدم React/NestJS/Prisma/PostgreSQL/Python/SymPy/Gemini وContent Studio القائم.
- لا تقرّر الإتقان أو سبب الخطأ بواسطة Gemini، ولا تستبدل قياس الفهم مستقلًا بإكمال درس أو تدريب بمساعدة.
- لا تُغيّر Golden أو التصنيفات المعلقة لإسكات فشل؛ احفظ سجل التعارضات.
- لا تنشئ صفحات فقط؛ كل وظيفة مع واجهة لها API وبيانات وقواعد قبول.
- لا تختلق اعتماد مدرس أو نشر مسودة، ولا تتجاوز حواجز جلسات الطلاب الحقيقيين، ولا تشغّل Runner غير محصّن.
- لا تغيّر قاعدة إنتاج، ولا تنشر Beta، ولا تشحن AI أو تستخدم بيانات حقيقية بلا تفويض.
- شغّل الفحوص المستهدفة، وتجنب الاختبارات الثقيلة غير الضرورية. الـGit commit بعد التأكد من عدم ضم الأسرار أو ملفات المستخدم غير ذات الصلة؛ لا push/merge دون إذن.

## التسليم
ملف واحد `qa-reports/V2.2-LEARNING-PATHS-DELIVERY.md`، يتضمن الحالات والأدلة والشيفرة/العقود والتقرير التشغيلي والقيود. أرفق طريقة تجربة محلية و6 خطوات يدوية لمسار الجبر ونتيجة التوصية.

**الهدف النهائي**: الطالب يستطيع أن **يدرس** أو **يختبر مستوى مهاراته**، ثم يحصل على **درس يفسر سبب التوصية** ويعالج الضعف المحتمل، ثم يحل سؤالًا جديدًا مستقلًا وتتحدث الأدلة؛ والمعلم يستطيع إنشاء هذه الدروس ونشرها بإصدارات محفوظة. توقف بعد التنفيذ وتسليم التقرير.
