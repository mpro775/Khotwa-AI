## الحد الأدنى للاختبارات الآلية
| المسار | الاختبار | الفشل المانع |
|---|---|---|
| المحتوى | إنشاء/تحقق/مراجعة/نشر lesson revisions وروابط questions | نشر مثال رياضي خاطئ، أو كشف draft |
| المهارات | mapping ↔ prereqs ↔ lesson، ومشاكل `GOLD-DIAG-015` وERR05 | تشخيص جازم بغير دليل أو تغيير مرجع بصمت |
| تقييم مستقل | sample + answer + evidence + summary | احتساب تلميح كنجاح مستقل أو إعادة استخدام سؤال التسريب |
| التوصية | repeated evidence، ambiguous، unsupported، missing lesson | توصية بدرس غير منشور أو سبب مخترع |
| العلاج | درس ← تدريب ← سؤال نقل مستقل مختلف | رفع mastery من مشاهدة درس أو إجابة بمساعدة |
| API/security | account/guest ownership، CSRF/Origin، idempotency، stale results | تسريب إجابات/بيانات أو سجل مكرر |
| الواجهة | API يربط شاشات Track/Lesson/Assessment/Recommendation | أزرار لا تعمل أو بيانات hardcoded |
| المواد | عدم اختلاط evidence بين الجبر/الفيزياء/البرمجة | حكم تخصصي من محرك خاطئ |

نفّذ `npm run lint`, `npm run typecheck`, `npm run build`, `npm run contracts:check`, وtests الموجهة. ثم E2E واحدة مع DB اختبار/محتوى تركيبية؛ لا migrations إنتاج.

## مثال قبول متكامل (السيناريو الضروري)
1. معلّم يدخل لوحة الاستوديو (بدور مخول)، ينشئ درس توزيع الأقواس، يراجعه وينشر نسخة معتمدة في DB اختبار.
2. الطالب يرى مادة الرياضيات ومسار الجبر ويفتح الدرس المنشور فقط.
3. يبدأ تقييمًا مستقلًا مرتبطًا بالمسار؛ يُرسل تحوّلًا غير مكافئ في مسألة توزيع الأقواس.
4. يعرض النظام الحكم الرياضي الصحيح ويقترح درس توزيع الأقواس بصياغة متحفظة مع source evidence.
5. الطالب يشاهد شرحًا، ويحل تدريبًا بمساعدة H2؛ تُحفظ النتيجة على أنها `with_support`.
6. ينتقل لسؤال **مختلف** لحفظ دليل مستقل، ويحلّه بلا تلميح؛ يرتقي التقدم بدليل مسجل، لا لمجرد العرض.
7. يعيد فتح الجلسة في نفس النوع المصرح به، ويتحقق من بقاء درس/مسألة pinned وعدم ضياع raw.
8. يُختبر رفض معرف تقييم لطالب آخر وعدم كشف النص المخفي.

إن كان Gemini معطلًا: هذا السيناريو ينجح بقوالب مراجعة، ولا يُعتبر اختبار AI حقيقي. إن كان المستخدم الحقيقي خارج نطاق `CODE-08` فلا تختبر ببيانات طلاب حقيقية واذكر القيد.

## ما يراجع يدويًا (مختصر)
- وضوح شرح «خطأ محتمل» وعدم وصم الطالب.
- صحة مثالين رياضيين في درس توزيع الأقواس أمام المراجع.
- قراءة RTL والأرقام والأقواس وتدرج H0–H4 في Chrome.
- الفرق المرئي بين «تدريب بمساعدة» و«فهم مستقل».
- مسار المعلم: مسودة/مراجعة/نشر/معاينة وإصدار سابق.

## القبول
- جميع وظائف الجبر الإلزامية في هذه المرحلة مثبتة التشغيل على قاعدة اختبار وواجهة؛ لا `BLOCKER` مفتوح في صحتها أو عزل البيانات.
- الرياضيات لا يصدر حكمها من Gemini، ومخرجات `unsupported/inconclusive/service_error` لا تتحول إلى رسوب.
- لا ادعاء نشر محتوى غير معتمد أو تشغيل Python Runner غير آمن.
- المستندات والـOpenAPI/Prisma/أنواع React متسقة مع المصدر.
- بنود الفيزياء والبرمجة غير الممكنة لغياب خدمة أو اعتماد تُسجّل `BLOCKED/CONFIGURATION_PENDING`، لا `PASS`.
