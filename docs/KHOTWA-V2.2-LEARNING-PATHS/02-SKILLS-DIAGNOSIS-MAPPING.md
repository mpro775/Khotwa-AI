# V2.2 / TASK-LP-02 — خريطة المهارات والتشخيص وربط الدرس بالخطأ

## الغاية
تحويل نتائج التحقق والتشخيص إلى **عنوان مهارة ودرس مناسب**، لا مجرد رسالة «إجابة خاطئة». يجب أن تكون التوصية قابلة للتفسير، متحفظة، وقابلة للتصحيح بدليل لاحق.

## إعادة استخدام الموجود
- `skills`, `skill_prerequisites`, `problem_skills` و`problem_revisions`.
- `diagnosis.ts`, `diagnosis-rules.ts`, `adaptive-tutoring.ts`, `skill_evidence`, `progress.ts`، والأحكام الرياضية من SymPy.
- أنماط `ERR-ALG-01..06` و`SK-ALG-01..08` وحدودها الفعلية في `05-CURRICULUM.md` و`06-MISCONCEPTIONS.md`.

## التنفيذ
1. أنشئ ربطًا مراجعًا أو قابلاً للمراجعة: `skillCode → primaryLessonRevision/lessonId`، `errorCode → candidateSkills[]`، `prerequisiteSkills[]`، و`problemRevision → assessedSkillCodes[]`؛ لا تكرر مراجع المحتوى أو تسجّل إتقانًا تلقائيًا للمهارات الثانوية من سؤال واحد.
2. استخدم `skill_prerequisites` القائمة لتحديد إن كانت المشكلة في المهارة المستهدفة أو في مقدمة سابقة؛ اعرض توصية بدرس واحد أساسي وسبب مختصر وخيار «عرض دروس أخرى».
3. خذ `verified_valid`/`verified_invalid` و`diagnosisCandidate` ومستوى الدليل وعدد محاولات مستقلة ومقدار المساعدة؛ لا تُساوِ **خطأً واحدًا** بتشخيص ضعف راسخ.
4. صنف الأدلة بوضوح: `not_assessed`, `needs_review`, `practicing_with_support`, `independent_evidence`, `insufficient_evidence`، أو اكتب mapping إلى الحالات القانونية الموجودة بدل مضاعفة حالات متضاربة.
5. لا يحق لـGemini تحديد `errorCode` أو `skillCode` أو ترقية إتقان الطالب. قد يصوغ شرحًا للنصيحة بعد نجاح فحصها، ولابد من fallback محلي.
6. **القضايا المفتوحة:** `GOLD-DIAG-015` و`ERR-ALG-05/calculation_divide ↔ SK-ALG-06` لا تُغلَق باستثناء نصي خاص أو تغيير Golden بلا اعتماد. إذا لم يتوفر ربط مراجَع، استخدم توصية عامة بالدرس/المهارة دون جزم، وسجل `mappingPending`.
7. تجنّب الأسئلة الملتبسة، والفصل بين الحساب الخاطئ وسبب الخطأ المفاهيمي. ينبغي أن تظهر عبارة «قد تحتاج إلى مراجعة...» عند ضعف الدليل.
8. اجعل خريطة الارتباط ذات إصدارات أو بصمة حتى لا يتغير تفسير محاولة قديمة بصمت بعد تعديل المنهج.

## أمثلة قبول
- تحوّل `٢(س + ٣)=١٠ → ٢س + ٣=١٠` غير المكافئ: يوصي بمراجعة **توزيع الأقواس** إذا كان الربط معتمدًا، ويكتب أنه **احتمال** لا حقيقة نفسية.
- انتقال صحيح بطريق بديل: لا يقترح علاجًا لمجرد أن الصيغة تختلف عن المثال المحفوظ.
- تشخيص غير محسوم: يعرض درس مراجعة عام أو سؤال تثبيت دون اختلاق كود خطأ.
- طالب أخطأ مرة ثم نجح مستقلًا في سؤالين مختلفين: يعيد تقييم الحاجة للمراجعة، ولا يحتفظ بوسم ضعف دائم.
- حجب مجال الكسور غير المعتمد يبقى ظاهرًا في واجهة المحتوى ولا يوجَّه إليه الطالب تلقائيًا.

اختبارات وحدات لأنماط الربط والأدلة القليلة/الكثيرة، ومقدمة قبل المهارة، ونسخ الإصدارات، وحماية Golden؛ اختبار API يثبت مصدر التوصية وليس فقط نصها.
