# C3 — تجربة STEM عربية أصيلة ومتعددة التمثيلات

## قواعد اللغة والرموز
- واجهة الطالب والتفسير التعليمي عربية واضحة؛ المعادلات تعرض `س`, `ص` في الجبر المدعوم، ويمكن وصف `جا`, `جتا` نصيًا فقط حيث لم يُعتمد تحليل المثلثيات؛ والأرقام العربية وفق ما يغطي محرك العرض القائم، مع **خريطة تحويل مضبوطة** إلى ترميز التحقق لا rewriting حر من LLM.
- في Python تبقى الكلمات `if`, `for`, `print` والـidentifiers في `dir=ltr`, مع تعليقات عربية اختيارية؛ لا تُقلب المسافات/الـindentation.
- تعرض الوحدات العلمية بمسارات مقروءة مثل `m/s`, `m/s²` مع تسمية عربية وأوصاف للنطق الصوتي.
- تجنب CSS `direction` عام على `code`, `math`, `input`; استخدم `bdi` أو مكوّنات عزل تدير الاتجاه والدلالة.

## نموذج تعليم متعدد الوسائط (مثال فقط)
**خاصية التوزيع:** سؤال نصي؛ تمثيل مستطيلات/جدول للمضاعفات؛ مثال محلول؛ سؤال «لماذا نضرب كلا الحدين؟»؛ تدريب جديد. الرسم/الجدول لا يحل مكان تحقق المحرك من المساواة.

**حركة منتظمة:** نص يصف المسافة والزمن؛ جدول `t,d`؛ محاكاة B2 إن كانت معتمدة؛ توقع قبل reveal؛ تفسير وحدات ودلالة ميل الرسم. عند تعطل المحاكاة يتاح جدول ووصف نصي دون ادعاء تجربة تم تشغيلها.

**حلقة برمجية:** tracing جدول متغيرات؛ Parsons؛ debugger إن كان B3 جاهزًا؛ لاحقًا كتابة كود عند Gate-R فقط.

## واجهات مقترحة
- `RepresentationSwitcher`: تبديل نص/جدول/رسم/محاكاة حسب registry وavailability؛ كل خيار يبين إنه شرح أو تقييم.
- `AccessibleEquation`: شكل عربي ظاهر + صيغة قابلة للنطق + نص بديل عند تعطل renderer.
- `KeyboardParsons`: أزرار «حرّك للأعلى/الأسفل» بدل drag فقط.
- `StudentPreferencesPanel`: تحكم عرض محلي/ملف الطالب حسب سياسة الموافقة؛ ليست بيانات طبية.

## اختبارات Golden
السالب `−`, القوسان, الكسور **غير المدعومة** لا تُفتح دون قبول رسمي، الكسور في نص تعليمي يمكن وصفها دون ادعاء حل رمزي، معادلة مختلطة RTL/LTR، مثال كود عربي التعليقات، جدول ذو رؤوس معنونة، تغيير التمثيل أثناء حفظ العمل، قارئ شاشة يقرأ النتيجة والحقل الصحيح.
