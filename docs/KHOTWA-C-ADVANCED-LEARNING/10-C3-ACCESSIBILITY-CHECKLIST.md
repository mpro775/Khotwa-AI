# C3 — متطلبات الوصول والاختبارات المستهدفة

## هدف تصميم قابل للقياس
استهداف **WCAG 2.2 AA** في الشاشات الجديدة مع مصفوفة استثناءات موثقة؛ هذا **هدف قبول هندسي** وليس تصريحًا بأن المنصة حاصلة على شهادة مطابقة.

## مصفوفة أساسية
| العنصر | المتطلب | كيف نختبر |
|---|---|---|
| لوحة المفاتيح | فتح/إغلاق/ترتيب/إرسال C1/C2/C4 دون فأرة؛ لا focus trap | مسار Tab/Shift+Tab/Enter/Space؛ ترتيب Parsons بأسهم/أزرار |
| تباين/تركيز | ظهور focus، تباين نص وعناصر وفق AA | فحص آلي + مراجعة يدوية متعلقة بالثيم |
| عرض RTL/LTR | العربية RTL؛ code/maths isolated LTR بالمواضع الضرورية | معادلة مختلطة نص/أرقام/علامات سالبة؛ Python indentation |
| دعم رسم B1 | عنوان/محاور ووصف للقيم واتجاهات التغير، جدول بديل | Screen-reader + جدول مقابِل |
| محاكاة B2 | وصف المدخلات/الناتج، تحكم قابل للوصول وتعليمات | اختبار keyboard وقراءة القيم بعد الحركة |
| المشروع | نقاط checkpoint؛ الأخطاء مرفقة بالحقل؛ لا معنى باللون وحده | تجربة forms مع عتاد مفاتيح |
| وسائط | alt مناسب، captions/transcripts إذا كانت media موجودة | إغلاق الوسائط ثم مواصلة التعلم |
| الحركة | `prefers-reduced-motion`؛ إيقاف animation غير ضروري | خيار تقليل الحركة ومراجعة حساسية الوميض |
| أحجام/أجهزة | تكبير 200–400% حسب القابلية، هاتف فعلي، بدون فقد وظيفة | browser zoom وعرض صغير |
| الوقت | تمديد أو تعطيل مؤقتات لا لزوم لها؛ عدم محو الإجابات | جلسة طويلة مع انقطاع شبكة |

## اختبارات عملية
- Unit/UI: accessibility selectors وأدوار/أسماء عربية، حالات error/help/focus.
- axe أو فاحص مشابه (إن موجود ضمن المشروع) + اختبار يدوي؛ لا تعتبر result صفر في أداة آلية إثبات توافق كامل.
- تحقق من VoiceOver/NVDA حيث متاح عند القبول اليدوي؛ وثّق الجهاز/المتصفح، لا تخترع نتيجة.
- لا تعامل عدم القدرة على التفاعل مع المحاكاة الرسومية فشل طالب؛ بديل تمثيل مع نفس هدف التعلم.

## Gate-C3
لا Publish محتوى `diagram` أو `video` بلا نص بديل/تفريغ لازم؛ لا release لنشاط ترتيبي لا يعمل بلوحة المفاتيح؛ لا ترميز correctness بلون وحيد.
